# 0004：失败恢复、可移植备份和邮件图片授权

[简体中文](0004-recovery-backup-image-privacy.zh-CN.md) | [English](0004-recovery-backup-image-privacy.en.md)

状态：已采纳，2026-11-07。范围：本地邮件客户端；Microsoft OAuth 配置不在本轮范围。

## 背景

任务结果已可持久显示，但缺少用户发起的恢复操作。EML ZIP 是邮件导出，不能恢复本地应用数据。图片代理仍会访问发送方的唯一地址，需要在访问前授权。

## 决策

- 失败恢复重新进入已有 flags/move 接受入口，以当前消息身份校验，并保留原任务。只处理未完成项目；发送结果未知时不提供自动重发。发送重试从加密原请求恢复正文和仍可用附件，附件丢失必须明确提示。
- 新增独立的可移植应用备份格式，保留原 EML 导出。使用固定成本的 scrypt 和分帧 AES-256-GCM；加密数据库快照、数据主密钥及数据库引用的出站附件/自定义背景。逐帧认证、顺序和结束标记防止截断/重排；不接受任意文件路径。
- 备份恢复先写隔离代际目录并验证数据库，预览后由用户确认启用。启动时读取原宿主密钥保护的指针和数据密钥，不替换 DPAPI 密钥，不覆盖运行中的数据库。旧代际保留；配置路径不由客户端指定。
- 恢复快照中的未结算远端写任务停止执行，未决发送改为待核对，自动回复和自动过滤关闭，防止恢复旧快照重放外部副作用。
- 图片策略存入独立的加密设置：默认阻止、单封允许、按完整发件地址信任、撤销。HTML URL 统一经过已有代理重写并携带邮件身份，服务端再次检查策略；内嵌图片不受影响。

## 后果与边界

恢复需要重启应用/本地服务。应用快照包括本地数据库内容，不承诺备份尚未下载的服务商附件；日志、临时图片缓存、桌面配对凭据和渲染器偏好不随应用备份迁移。备份口令丢失无法恢复。界面应显示范围、版本、数量与暂停行为。文件和请求均有明确预算，测试使用隔离数据库和合成邮件。

## 验证

需要覆盖错误口令、篡改/截断/路径攻击、跨主密钥恢复、重启切换、原库保留、待发任务暂停、拒收重试的正文/附件恢复、过期目标拒绝，以及图片授权前零上游请求和撤销。
