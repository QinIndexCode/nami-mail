# 接入外部 MCP 服务器（NamiMail Agent）

[English](mcp-servers.en.md) | [使用指南](usage.zh-CN.md) | [模型配置](providers.zh-CN.md)

邮件助理可以作为 MCP 客户端接入通过 stdio 启动的外部 MCP 服务器（如 Claude Code、filesystem、GitHub 等），在对话中调用其工具，扩展能力范围。

## 快速开始

1. 打开 NamiMail Agent 工作区，进入**设置 → MCP 服务器**。
2. 点击**添加服务器**，填写显示名称与启动命令（如 `npx -y @modelcontextprotocol/server-filesystem`）。
3. 点击**保存并检查**；握手与工具发现成功后，服务器状态变为"连接已验证"。
4. 保持**启用此服务器**，之后对话开始时助理会自动连接并加载其工具。

停用或删除的服务器不会在对话中加载工具。

## 配置字段

| 字段 | 说明 |
| --- | --- |
| 显示名称 | 仅用于在 Nami Mail 内区分服务器 |
| 启动命令 | 本地可执行文件或已安装的命令，如 npx、python、node |
| 启动参数 | 每行一个参数，与命令行参数一一对应；单个参数最长 1,024 字符 |
| 环境变量 | 每行一个；值仅写入本地加密存储，不会回显；删除整行可移除已保存的变量（变量名仅允许字母、数字和下划线且不能以数字开头，值最长 8,192 字符） |
| 工作目录 | 可选；服务器进程启动时的工作目录，最长 2,048 字符 |
| 连接超时 | 毫秒，可设置 5,000 到 180,000 |
| 启用此服务器 | 关闭后助理不会连接该服务器，也不会加载其工具 |

环境变量按"系统环境 + 服务器配置"合并注入到服务器进程。更新服务器时，未显式修改的环境变量会被保留——只改名称或超时不会清空已保存的密钥。

## 工具加载与命名

- 启用后，对话开始时自动加载该服务器的工具；工具显示为"服务器前缀 + 工具名"，例如 `mcp-server-xxx.get_weather`。
- 单个服务器最多加载 100 个工具；单条 MCP 响应受大小限制，超大结果会按安全上限截断。
- 服务器配置变化后按配置指纹重连，避免无谓断连。

## 读写分类与确认

- **只读工具**：仅显式声明只读且非破坏的工具按只读执行，无需确认。
- **写工具**：其余一律按写工具对待——桌面端执行前会弹出确认对话框；对外部调用者（CLI/MCP 桥）隐藏，不可被外部调用。
- 工具输入在执行前都会经过 schema 校验，非法输入不会到达服务器。

## 云端邮件内容授权

- 不接触邮件数据的外部 MCP 工具，在未授权云端邮件内容时也可以用于对话。
- 内置邮件工具（读取、草稿等）仍受云端授权门控：未授权时，云端模型无法通过任何内置工具读取邮件。
- 因此接入外部 MCP 服务器不会绕过邮件数据的云端授权边界。

## 安全与排错

- 服务器命令在本机执行，可能读写本机文件或调用外部服务；请只添加你信任的服务器。
- 环境变量（常含 API 密钥）加密保存在本机，接口只返回变量名、不回显值。
- 服务器删除需二次确认；删除后本地配置与密钥一并移除。

常见错误：

| 提示 | 原因与处理 |
| --- | --- |
| 连接失败 | 启动命令、参数、工作目录或环境变量有误；修正后重试 |
| 握手失败 | 服务器不兼容客户端请求的 MCP 协议版本（支持 `2025-03-26`、`2025-06-18`），或进程在初始化后退出 |
| 超时 | 服务器在超时时间内没有响应；检查命令与状态，或调大连接超时 |
| 配置在检查期间已更新 | 保存期间配置被修改；再次保存并检查 |
