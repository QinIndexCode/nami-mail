# 邮件助理使用指南（NamiMail Agent）

[English](usage.en.md) | [模型配置](providers.zh-CN.md) | [架构](architecture.zh-CN.md)

NamiMail Agent 是内置的邮件 AI 工作区：本地检索、来源引用，并可在明确的账户范围内管理草稿。开始使用前，请先[配置至少一个可用模型](providers.zh-CN.md)。

## 对话管理

- **新建对话**：工作区顶部新建；新对话默认使用默认模型。
- **搜索/重命名/删除**：对话列表支持搜索；重命名与删除均需二次确认。
- 未配置模型或模型服务不可用时，会话和你的输入会被保留，并给出可恢复的下一步提示，不会把 Provider 超时伪装成已完成。

## 邮件范围（Scope）

提问前可选择分析范围，范围决定助理能检索哪些邮件与调用哪些工具：

| 范围 | 含义 |
| --- | --- |
| 全部账户 | 分析所有邮箱账户的邮件，适合跨账户汇总 |
| 当前账户 | 仅分析当前选中邮件所属账户的邮件（需先选中邮件） |
| 当前邮件 | 仅分析当前选中的单封邮件内容（需先选中邮件） |

范围外的邮件内容不会被检索或发送；云端模型发送的内容始终受所选范围约束。

## 提问与生成

- 在输入框输入问题并发送；生成过程中可点击**停止生成**。
- 可**上传文件**作为对话上下文附件；删除附件会将其移出上下文。
- 本地模型不会把邮件内容发送到云端；云端模型在未授权邮件内容前只会收到你主动输入的文字，授权后也只发送所选范围内的内容。
- 发送邮件和高风险操作始终需要你的确认。

## 来源引用

助理引用邮件时，回复中会显示**来源邮件**面板，可展开查看引用的消息、主题与发件人。检索基于本机加密存储的 RAG 索引，只覆盖对话范围内的邮件。

## 草稿与高风险操作

- 助理可在范围内创建、编辑草稿；发送始终复用既有邮件服务的幂等提交语义。
- 写操作（发送、删除等）执行前会弹出**需要你的确认**对话框：可**确认继续**或**拒绝**；确认有过期时间，过期后该操作不会执行。
- 拒绝或过期后，回复中会明确显示"此操作未执行"。

## 故障恢复

- 模型未配置、未授权邮件内容或 Provider 健康检查失败时，界面保留会话并给出可恢复提示。
- 流式生成中断时可重试；"助理暂时不可用"提示表示本地服务不可用，请确认应用仍在运行。
