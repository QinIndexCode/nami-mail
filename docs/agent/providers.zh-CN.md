# 模型提供商配置（NamiMail Agent）

[English](providers.en.md) | [使用指南](usage.zh-CN.md) | [架构](architecture.zh-CN.md)

邮件助理需要至少一个可用的模型提供商才会开始读取或发送任何邮件内容。本文说明如何配置模型连接、密钥与云端邮件内容授权。

## 快速开始

1. 打开 NamiMail Agent 工作区，进入**设置 → 模型提供商**。
2. 点击**添加模型**，选择接口类型并填写服务地址、模型名称等字段。
3. 点击**保存并检查**；连接验证通过后即可开始对话。

未配置任何模型时，助理界面会提示"先设置一个可用模型"，不会读取或发送邮件内容。

## 支持的接口类型

| 接口类型 | 说明 |
| --- | --- |
| OpenAI 兼容接口 | 可连接绝大多数服务，如 DeepSeek、通义千问、Kimi、智谱、豆包、vLLM、LM Studio 等 |
| Ollama（本机） | 本机 Ollama 服务，默认地址建议 `http://127.0.0.1:11434/v1` |
| Anthropic Claude（原生协议） | Anthropic Messages API，例如 `https://api.anthropic.com` |
| Google Gemini（原生协议） | 例如 `https://generativelanguage.googleapis.com/v1beta` |
| OpenAI Responses（原生协议） | 例如 `https://api.openai.com/v1` |
| 自定义（Custom） | 预留类型，用于未来或用户自定义的 Provider 适配器 |

## 字段说明

| 字段 | 要求 |
| --- | --- |
| 接口类型 | 选择上面的类型之一 |
| 显示名称 | 仅用于在 Nami Mail 内区分模型 |
| 服务地址 | 使用 HTTPS；仅在本机服务时可使用回环 HTTP 地址 |
| 模型名称 | 填写服务提供的准确模型 ID |
| 请求超时 | 毫秒，可设置 1,000 到 120,000 |
| API 密钥 | 仅写入本地加密存储，保存后不会再次显示 |

API 密钥行为：

- 保存后密钥只写不回显；编辑模型时**留空**表示保留现有密钥，可勾选"保存时移除现有密钥"清除。
- 本机或无需鉴权的服务可留空密钥。
- 密钥不会出现在普通设置、日志、浏览器状态或 IPC 输出中。

## 云端邮件内容授权

- 云端模型（Claude、Gemini、OpenAI、OpenAI 兼容等）**默认不能读取邮件内容**。需要打开"允许向云端模型发送选定邮件内容"，并确认该服务符合你的数据处理要求。
- 开启后，发送给模型的内容仍受**对话范围**约束：只发送你选择范围内的邮件内容，并在发送前显示披露提示。
- 未开启时，云端模型只会收到你主动输入的文字。
- 本机 Ollama 不会把邮件内容发送到云端，不适用此开关。
- 授权不是由 API 密钥存在与否推断的：未显式开启时，云端模型一律不能读取邮件。

## 默认模型与状态

- **设为默认模型**：新建对话会优先使用该模型。
- 状态标记：`配置完整`、`连接已验证`、`连接需复查`、`连接不可用`；本地模型与云端模型会分别标识。
- 连接检查失败时配置会被保留，可修正后重试；常见错误包括认证拒绝、超时、服务不可达、限流和配置在检查期间被修改。
