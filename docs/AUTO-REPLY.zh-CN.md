# 自动回复

[简体中文](AUTO-REPLY.zh-CN.md) | [English](AUTO-REPLY.en.md)

Nami Mail 的自动回复是按账户开启的可选功能：同步到新收件箱邮件后，先经过一组本机离线规则筛选，再把候选邮件交给模型评估并草拟回复。Agent 起草的回复在发送前必须经你在确认弹窗中批准；模板模式可按模板选择跳过确认。配置入口在**设置 → Agent → 自动回复**。

## 启用与账户范围

- **启用自动回复**后，还需勾选**监控哪些账户**——留空则不运行。
- **每日回复上限**限制每个账户每天最多发出的自动回复数量（默认 30，范围 0–500）。

## 回复方式与双模型

- **Agent 起草（llm 模式）**：由模型评估来信是否值得回复并生成纯文本草稿。可分别指定**判定初筛模型**与**草稿生成模型**（留空则使用默认模型），例如用轻量模型快速初筛、用更强的模型写草稿。
- **固定模板（template 模式）**：不调用模型，用模板原文回复。模板支持占位符替换：`{{senderName}}`、`{{senderAddress}}`、`{{senderDomain}}`、`{{subject}}`，最长 2000 字符；模板可单独勾选跳过发送确认。

## 判定范围（离线规则，不调用模型）

范围规则在模型介入之前、完全在本机执行，用于缩小候选面：

- **仅回复联系人**：只回复本机通讯录中的发件人。
- **生效日期窗口**：可设定起止日期，窗口之外不回复。
- **同一会话只回复一次**：默认开启，按线程永久去重。
- **自定义规则**（最多 50 条）：按字段（发件人 / 发件域 / 主题）+ 运算符（包含 / 不包含 / 等于）+ 动作（回复 / 忽略）组合；`忽略`规则优先生效，其余`回复`规则构成白名单——没有命中任何`回复`规则的邮件不会进入模型评估。

在此之上还有一层固定的离线初筛，以下邮件永远不会触发自动回复：垃圾邮件文件夹中的邮件、带 `Auto-Submitted` 头的自动邮件、营销邮件（含 `List-Unsubscribe` 或 `Precedence: bulk/list/junk`）、Gmail 的推广/社交/更新分类标签、无发件人邮件与退信。

## 确认、审计与敏感内容

- Agent 起草的回复一律弹出确认卡片（5 分钟内有效），可批准发送或拒绝；等待确认与已发送的结果会以通知提示反馈。
- 被拒绝或发送失败的回复会记入本机决策记录，可在界面中回看。
- 含敏感关键词（如密码、验证码等）的来信会被标记并路由到最高优先级的确认面，模型仍会再次复核。

## 沙盒模拟器（Dry-Run）

设置中提供零副作用的自动回复沙盒：可输入测试邮件或从收件箱载入真实样本，端到端展示链接清洗的 Token 节约、范围规则与离线初筛的命中情况、模型决策理由、拟定草稿预览及各阶段耗时。沙盒运行在只读上下文中，不会发出任何邮件。

## 数据与边界

- llm 模式会把清洗后的邮件内容（长跟踪链接被归一化、内联图片被压缩以节约 Token）发送给你配置的模型服务商；未配置模型时功能不可用，配置失效会在设置页给出明确警告。
- template 模式完全离线，不向任何第三方发送邮件内容。
- 自动回复只处理同步落库后的新收件箱邮件，不会读取历史邮件，也不会改动服务商端的自动回复/假期设置。
