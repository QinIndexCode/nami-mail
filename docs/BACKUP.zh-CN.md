# 应用备份与恢复

[简体中文](BACKUP.zh-CN.md) | [English](BACKUP.en.md)

“设置 → 数据与隐私”提供口令保护的 `.namibak` 应用快照。原有 EML ZIP 导出继续用于迁移邮件原文；它不等同于应用恢复。

## 备份范围

包含本地数据库中的邮件正文与元数据、账户与凭据、联系人、日历、模板、过滤规则、设置、Agent 配置、会话和记忆，以及数据库引用的本地出站附件和自定义背景。未下载的收件附件仍在服务商处；日志、临时图片缓存、桌面配对和渲染器本地偏好不随备份迁移。

备份包含敏感凭据。口令至少 12 个字符，导出时需要重复输入；请分开保管口令与备份文件。口令遗失无法恢复。单份备份最多 3 GiB、20,000 个文件；浏览器下载会持有完整文件，较大备份需要相应内存。创建 SQLite 快照时，本地服务可能短暂忙碌。

## 导出与恢复

1. 在“加密应用备份”中输入并重复口令，下载 `.namibak` 文件。
2. 在当前安装或另一台机器的空白安装中，选择备份文件，输入原备份口令，点击“校验并预览”。校验失败不改变当前数据。
3. 核对时间、数据库版本和各类数据数量，勾选确认后启用恢复。
4. 完全退出再打开桌面应用；浏览器开发模式需要重启本地服务。下次启动使用已校验的独立数据目录，原数据保留。

恢复是切换整份应用快照，不是与当前库合并。确认后继续在旧库产生的修改不会带入恢复库，因此应先备份当前状态，确认后及时重启。关闭预览会尽力清理尚未启用的恢复暂存；已启用的数据目录不会被清理。

## 恢复后的外部操作

快照里的未结算远端任务停止执行。待发送或正在发送的记录标为投递待核对，请先检查服务商已发送文件夹；不会因恢复而自动重发。自动回复和自动过滤关闭，需要审阅后重新开启。已经提交的发送记录保持原结果，但它们代表备份时刻的状态。

## 加密与换机

文件使用固定成本 scrypt 派生密钥、按顺序认证的 AES-256-GCM 分帧和认证结束标记。快照保留加密数据库及其数据密钥，二者均在口令加密文件内。导入时用目标安装的宿主密钥重新保护数据密钥和启动指针；Windows DPAPI 记录不被复制或替换，因此不要求新机器拥有旧 Windows 用户的 DPAPI 上下文。原目录和旧恢复代际保留，请自行将其视为需要保护的数据。

实现与验证决策见 [ADR 0004](development/decisions/0004-recovery-backup-image-privacy.zh-CN.md)。
