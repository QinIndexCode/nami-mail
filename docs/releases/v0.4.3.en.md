# Nami Mail 0.4.3

[简体中文](v0.4.3.zh-CN.md) | [English](v0.4.3.en.md)

Nami Mail 0.4.3 is a major release centered on comprehensive settings UI/UX visual ergonomics, agent context budget management, and intelligent auto-reply optimization: completely refactors the visual hierarchy and micro-interactions of all settings panels and dialogs; introduces email link sanitization and token reduction for auto-reply evaluation; implements model context window and max output budget estimation, long tool output pruning, and automated conversational history compression; introduces a zero-side-effect auto-reply dry-run simulator sandbox; and cleanly reorganizes external connections (built-in MCP tools, exposed local MCP servers, and external CLI).

## Download

Download only the Windows `.exe` installer listed on this release page. The versioned ZIP, JSON update manifest, `latest.yml`, and `.blockmap` are distribution and in-app update resources, not manual installers — do not extract or run them yourself.

## Update and signing status

- Pre-release validation: CI validation passed in full (typecheck, lint, unit & integration tests, e2e, desktop smoke, and dependency audit); the release job packages, runs package smoke, and verifies draft assets before promoting the release to public.
- The `0.4.3` Windows installer is not Authenticode signed. Windows SmartScreen may show an "unknown publisher" warning. Do not bypass Windows security warnings; get the installer only from this release page.
- In-place upgrades keep existing local data; no re-login or re-authorization is required by this update alone.

## Highlights

- **Settings UI/UX & Aesthetic Overhaul**:
  - Removed wall-of-text static subtitles and redundant explanatory paragraphs across all settings panels, switching to elegant inline hover question-mark tooltips for a clean, scannable layout;
  - Harmonized baseline vertical alignment for helper icons and labels, standardizing control heights (32px) and border radius rhythm;
  - Unified copy icon click animations across settings panels with a smooth checkmark micro-interaction transition identical to the email management account card;
  - Decomposed and modularized the monolithic `styles.css` into dedicated stylesheet modules (`settings.css`, `agent.css`, `modals.css`, `connections.css`, `appearance.css`) for improved maintainability;
  - Fixed subpanel scrollbar layout shift and width flickering when toggling the exposed MCP sub-tab.
- **External Connections Clarification & Cross-Platform IPC Abstraction**:
  - Clearly segregated internal built-in MCP client tools, locally exposed MCP servers (for Claude Desktop, Cursor, etc.), and external `namimail` CLI tool suites;
  - Enhanced exposed MCP service lifecycle controls (start, stop, restart) with one-click JSON configuration snippets and clear permission badges (Read-Only, Send-Confirmed, Full-Access);
  - Added management and token revocation capabilities for paired external CLI sessions;
  - Abstracted unified cross-platform local IPC transport layer (`SupportedBrokerTransport`), supporting both Windows Named Pipes and POSIX Unix Domain Sockets with strict UID ownership and 0600 file permissions.
- **Auto-Reply Link Sanitization & Token Preservation**:
  - Automatically cleanses and shortens HTML anchors, Markdown links, tracking/marketing query parameters, and base64 data URIs before feeding email bodies to LLMs for reply-value screening;
  - Accurately normalizes unsubscribe URLs into compact `[退订链接]` tags and transforms verbose tracking URLs into minimal root domain tags (e.g. `[链接: github.com]`);
  - Collapses repetitive consecutive links, significantly reducing prompt token waste and latency while improving LLM judgment accuracy.
- **Context Budget Estimation, Tool Pruning & Auto History Compression**:
  - Supports configuring context window size (Tokens) and maximum output size (Tokens) per model provider;
  - Automatically estimates prompt, history, and system instruction token consumption throughout the agent tool execution loop;
  - Triggers intelligent pruning on voluminous tool outputs (such as bulk search results or huge email texts) when approaching context thresholds (e.g. 75% capacity), preventing token limit exceptions;
  - Automatically summarizes and condenses earlier multi-turn conversational turns when context budgets tighten, allowing complex multi-step agent workflows to complete smoothly.
- **Auto-Reply Dry-Run Simulator (Sandbox) & Visual Polish**:
  - Added a zero-side-effect testing sandbox in AI Mail Agent settings;
  - Allows entering custom test emails or loading recent unread/inbox messages to simulate the entire auto-reply evaluation pipeline;
  - Displays real-time metrics: link sanitization token savings, scope filter rules matches (whitelist/blacklist/DND), LLM decision reasoning, and drafted response previews;
  - Polished dialog animations and interactions: added smooth cubic-bezier entry transitions (`sandbox-reveal`), pulsing skeleton loader during evaluation, sender email input styling alignment, and smooth viewport anchoring upon completion;
  - Executes completely in-memory with zero side-effects — no emails are sent and no approval cards are persisted.
- **Typewriter Streaming Animation & Draft Visuals**:
  - Integrated high-performance adaptive typewriter stream-in (`useTypewriter`) for simulated draft preview, dynamically pacing steps and intervals to smoothly reveal long texts within 1.5 seconds;
  - Added pure CSS blinking breathing cursor (800ms cycle) and one-click "Show Full" skip control;
  - Native fallback support for OS-level `prefers-reduced-motion: reduce` preference with instant reveal.
- **End-to-End Performance Metrics & Latency Telemetry**:
  - Integrated `performance.now()` high-precision stage timings across server-side sandbox execution, reporting screening latency, token compaction latency, scope rule latency, LLM model latency, and total elapsed time;
  - Rendered lightweight latency capsule badges (`sandbox-latency-pill`) in the result header with detailed tooltip breakdown on hover;
  - Integrated `recordAgentTiming` and `slow-agent` metrics into client-side performance telemetry.

## Security & Scope

- This release introduces no new outbound network attack surface: local-first principles remain intact with no public ports opened;
- Local exposed MCP and CLI communicate strictly over authenticated local IPC (Windows Named Pipes or Unix Domain Sockets) with pairing credentials and granular access controls;
- The auto-reply simulator runs strictly in dry-run mode with guaranteed zero external side-effects;
- Update trust root remains unchanged: GitHub ZIP update assets are verified with Ed25519 manifest signatures against the embedded public key.

## Known limitations

- Windows x64 desktop only.
- Local retrieval does not ingest attachment bodies. Chinese is indexed per character, so questions whose wording differs greatly from the mail rely on query expansion and hits may include noise.
- Availability, quotas, and output accuracy of cloud models and translation services depend on the chosen service; machine translation is only a reading aid.
