# Nami Mail 0.4.3

[简体中文](v0.4.3.zh-CN.md) | [English](v0.4.3.en.md)

Nami Mail 0.4.3 is a major release centered on system settings aesthetic overhaul, agent streaming stability and visual polish, mail folder navigation modes, dual-model auto-reply pipelines with a dry-run sandbox, and mail filter reliability: introduces Tree mode and Focus mode toggles for mail folders; completely resolves agent streaming text loss during rendering and refines visual presentation; adds independent model configuration for auto-reply evaluation vs reply drafting; fixes mail filter rules; provides a zero-side-effect auto-reply testing sandbox; polishes add-account onboarding guidance; implements context budget estimation with tool pruning and auto history compression; and abstracts cross-platform local IPC architecture for external connections (built-in MCP, exposed MCP, and CLI).

## Download

Download only the Windows `.exe` installer listed on this release page. The versioned ZIP, JSON update manifest, `latest.yml`, and `.blockmap` are distribution and in-app update resources, not manual installers — do not extract or run them yourself.

## Update and signing status

- Pre-release validation: CI validation passed in full (typecheck, lint, unit & integration tests, e2e, desktop smoke, and dependency audit); the release job packages, runs package smoke, and verifies draft assets before promoting the release to public.
- The `0.4.3` Windows installer is not Authenticode signed. Windows SmartScreen may show an "unknown publisher" warning. Do not bypass Windows security warnings; get the installer only from this release page.
- In-place upgrades keep existing local data; no re-login or re-authorization is required by this update alone.

## Highlights

- **Mail Folder Navigation Modes (Tree Mode & Focus Mode)**:
  - Added one-click switching between a hierarchical tree view (Tree mode) and a focused flat view (Focus mode) for mail folders;
  - Improved folding, expansion, and navigation ergonomics for deeply nested mailboxes.
- **Account Email Address Copy**:
  - Added one-click copy button for account email addresses in the account management list with a smooth checkmark micro-interaction transition.
- **Agent Output Reliability & Visual Refinement**:
  - Completely resolved edge cases where streaming output deltas were dropped (draining queued tail deltas) during rapid conversation switches or component re-renders;
  - Polished agent output visual presentation, including collapsible tool execution cards, search status chips, and progress feedback;
  - Integrated adaptive typewriter streaming effect (`useTypewriter`) with a pure CSS blinking cursor, one-click skip control, and `prefers-reduced-motion` support.
- **Auto-Reply Dual-Model Separation & Dry-Run Sandbox**:
  - Added independent configuration for auto-reply "screening/evaluation model" and "draft generation model", allowing cost-effective, high-throughput models for triage and powerful models for drafting;
  - Added a zero-side-effect "Auto-Reply Sandbox Simulator" allowing users to test custom emails or load inbox messages to inspect link sanitization token savings, filter rules, LLM reasoning, and generated drafts;
  - Built-in automatic email link sanitization, tracking parameter stripping, and base64 image reduction, saving significant prompt tokens.
- **Mail Filter Rules Bugfix**:
  - Fixed condition evaluation and state synchronization anomalies in mail filter rules, ensuring automated filtering actions on senders, subjects, and email bodies execute reliably.
- **Add-Account Onboarding & Guidance Polish**:
  - Streamlined the add-account dialog with clearer configuration steps and authentication tips for mainstream mail providers;
  - Standardized input validation feedback to avoid misleading password fields or dead-end states.
- **Settings UI/UX & Aesthetic Overhaul**:
  - Removed wall-of-text static subtitles and redundant explanatory paragraphs across all settings panels, switching to elegant inline hover question-mark tooltips;
  - Harmonized baseline vertical alignment for helper icons and labels, standardizing control heights (32px) and border radius rhythm;
  - Unified copy icon click animations across settings panels with a smooth checkmark micro-interaction transition;
  - Decomposed and modularized the monolithic `styles.css` into dedicated stylesheet modules (`settings.css`, `agent.css`, `modals.css`, `connections.css`, `appearance.css`);
  - Fixed subpanel scrollbar layout shift and width flickering when toggling the exposed MCP sub-tab.
- **External Connections Clarification & Cross-Platform IPC Abstraction**:
  - Clearly segregated internal built-in MCP client tools, locally exposed MCP servers (for Claude Desktop, Cursor, etc.), and external `namimail` CLI tool suites;
  - Enhanced exposed MCP service lifecycle controls (start, stop, restart) with one-click JSON configuration snippets and clear permission badges;
  - Added management and token revocation capabilities for paired external CLI sessions;
  - Abstracted unified cross-platform local IPC transport layer (`SupportedBrokerTransport`), supporting both Windows Named Pipes and POSIX Unix Domain Sockets with strict UID ownership and 0600 file permissions.
- **Context Budget Estimation, Tool Pruning & Auto History Compression**:
  - Supports configuring context window size (Tokens) and maximum output size (Tokens) per model provider;
  - Automatically estimates prompt, history, and system instruction token consumption throughout the agent tool execution loop;
  - Triggers intelligent pruning on voluminous tool outputs when approaching context thresholds (e.g. 75% capacity);
  - Automatically summarizes and condenses earlier multi-turn conversational history when context budgets tighten.
- **Auto-Update & Backend Service Stability Hardening**:
  - Completely resolved the 30-second shutdown timeout and false data-busy errors during in-app update preparation by explicitly terminating and destroying active Server-Sent Events (SSE) long-polling streams;
  - Promptly destroyed application windows and configured a 1-second fallback hard-exit timer upon updater launch so the external installer can take over seamlessly;
  - Added proactive pre-flight disk space verification before downloading and installing updates, gracefully blocking update failures and guiding users on storage requirements;
  - Restructured the sidebar footer layout into clean dedicated rows, permanently eliminating horizontal text squishing and vertical line wraps;
  - Replaced improper usage of `--button-text` on sidebar update pills and badges with WCAG-compliant design tokens, accompanied by smooth fade-in transitions;
  - Fixed cascading gate locks where `desktopAgentBrokerRecoveryGate` failed to restore to `accepting` upon transient update prep errors;
  - Added unhandled promise rejection logging and defensive guards to the utility process, avoiding abrupt process exits.
- **End-to-End Performance Metrics & Latency Telemetry**:
  - Integrated `performance.now()` high-precision stage timings across server-side sandbox execution (screening, compaction, scope rules, LLM latency, total elapsed time);
  - Rendered lightweight latency capsule badges (`sandbox-latency-pill`) in result headers with hover breakdown;
  - Integrated `recordAgentTiming` and `slow-agent` metrics into performance telemetry.

## Security & Scope

- This release introduces no new outbound network attack surface: local-first principles remain intact with no public ports opened;
- Local exposed MCP and CLI communicate strictly over authenticated local IPC (Windows Named Pipes or Unix Domain Sockets) with pairing credentials and granular access controls;
- The auto-reply simulator runs strictly in dry-run mode with guaranteed zero external side-effects;
- Update trust root remains unchanged: GitHub ZIP update assets are verified with Ed25519 manifest signatures against the embedded public key.

## Known Issues & Limitations

- **Outlook / Hotmail Sign-in Currently Unavailable on Clean Installs (Tracking Issue #120)**:
  - Microsoft has deprecated Basic Authentication (IMAP/SMTP passwords) for Outlook.com, requiring OAuth2;
  - Official builds do not yet embed an official Azure OAuth client ID, meaning "Sign in with Microsoft" is disabled out of the box;
  - Workaround: Users can configure `NAMI_MAIL_MICROSOFT_OAUTH_CLIENT_ID` in `%APPDATA%\Nami Mail\nami-mail.env`; this will be resolved once an official Azure application registration is completed by the maintainer in a future release.
- **Platform**: Windows x64 desktop only.
- **Search**: Local retrieval does not ingest attachment bodies. Chinese is indexed per character, so queries differing greatly from mail content rely on query expansion and may include noise.
- **Third-Party Services**: Cloud model and translation service availability and quotas depend on chosen providers.
