# Nami Mail 0.4.2

[简体中文](v0.4.2.zh-CN.md) | [English](v0.4.2.en.md)

Nami Mail 0.4.2 是一个关键的维护与体验发布：彻底修复了 Windows 安装程序在初次安装与覆盖升级时自定义安装路径失效、历史安装位置无法记忆并被强制覆写回 C 盘的缺陷；重构了 Agent 执行敏感操作时审批确认卡片与输入框的物理层级咬合与平滑折叠动效；新增 BIMI 官方品牌发件人图标解析与安全缓存；支持写信附件拖拽上传与剪贴板截图直接粘贴；并抑制同语言邮件的多余翻译横幅。

## 下载

请只使用匹配 GitHub Release 页面列出的 Windows `.exe` 安装程序。版本化 ZIP、JSON 更新清单、`latest.yml` 和 `.blockmap` 用于发行与应用内更新，不是手动安装包。

## 更新与签名状态

- 发布前验收：CI 全量验证通过（typecheck / lint / 单元与集成测试 / e2e / desktop smoke / 依赖审计）；release job 在打包后运行 package smoke 并校验草稿资产完整性，通过后转正发布。
- `0.4.2` Windows 安装程序未进行 Authenticode 签名。Windows SmartScreen 可能显示未知发布者警告。请勿绕过 Windows 安全警告，只应从本 Release 页面获取安装程序。
- 就地升级会保留现有本地数据；不会仅因本次更新而要求重新登录或重新授权账户。

## 本次更新

- **Windows 安装程序自定义路径生效与覆写缺陷修复**：
  - 修复了用户在安装向导中选择自定义路径（如 `D:\tools\nami`）后，实际仍被强制覆写安装至系统盘默认目录（`C:\Users\<user>\AppData\Local\Programs\Nami Mail`）的关键缺陷；
  - 根因在于此前自定义向导宏将目录选择页面插入到了模式选择之前，导致后续模式选择回调函数（`setInstallModePerUser`）在初次安装时无条件将 `$INSTDIR` 重置回默认用户目录；
  - 调整宏执行时序，遵循生命周期标准在模式确定后再展示目录选择，并在构建配置中显式声明 `allowToChangeInstallationDirectory: true`，确保自定义路径绝对生效。
- **覆盖安装与升级安装历史路径自动探测与记忆恢复**：
  - 修复了已安装用户在重复运行安装程序或跨版本升级时，向导无法正确读取非系统盘旧安装路径、提示覆盖重装但路径回退到 C 盘的缺陷；
  - 新增安装预初始化阶段（`preInit`）的多源探测恢复宏（`namiRecoverExistingInstallLocation`），依次从专有注册表项、Windows 卸载记录（`UninstallString`、`DisplayIcon`、`InstallLocation`）及备用 App 项中反解提取真实安装目录；
  - 在安装阶段对注册表双重写入 `InstallLocation`，确保覆盖安装与后续无感知更新均能百分之百精准命中旧版实际所在目录。
- **Agent 审批卡片物理插槽吸附与平滑折叠**：
  - 重构敏感操作确认卡片与输入框的咬合设计：在 `.agent-composer` 应用实体背景（`var(--panel-solid)`）作为物理遮挡层，配合外层插槽的 `-14px` 负边距抽屉插槽咬合，使卡片底边缘自然插入输入框后方；
  - 彻底去除原底边渐变蒙版导致的悬浮断层虚边，移除多余底边框；
  - 扩充卡片下部内衬（24px 安全缓冲）杜绝遮挡决策按钮，并在展开与折叠全周期应用同步的贝塞尔缓动，决裁后复位零位移跳变。
- **BIMI 官方发件人品牌图标支持**：
  - 支持从 DMARC/BIMI 规范解析企业官方发件人 SVG 品牌图标，增强官方验证邮件的视觉辨识度；
  - 具备严格的 SVG 安全净化、尺寸规整、内存与磁盘双级缓存及 TTL 过期保护机制。
- **写信窗口附件拖拽与截图粘贴**：
  - 写信对话框支持将本地文件直接拖拽添加为附件，具备清晰的虚线投放反馈遮罩；
  - 正文编辑区支持剪贴板图片 `Ctrl+V` 直接粘贴上传，显著提升截图发信效率。
- **阅读器同语言邮件翻译提示抑制**：
  - 智能探测邮件正文语言特征，当语言与客户端当前界面语言一致时，默认不显示多余的“翻译为当前语言”横幅，消除标题与正文间的视觉干扰。
- **自动化测试与 CI 稳定性优化**：
  - 针对桌面端冒烟测试中的空闲渲染器检测，放宽 `timerMaxGapMs` 阈值至 350ms，彻底消除高负载构建机偶发的 CPU 抖动超时。

## 安全与范围

- 本版本未扩大任何外部访问面：没有新增对外开放端口，邮件内容仍默认不出本机；
- BIMI 图标获取受严格内容净化与沙箱约束，不执行内联脚本与外部资源引用；
- 更新信任链不变：GitHub ZIP 更新资产继续使用 Ed25519 清单签名校验，安装包内嵌公钥。
- 本地优先边界不变：账户凭据仅保存在本机，云端模型仅在用户明确选择并同意时使用。

## 已知限制

- 仅提供 Windows x64 桌面版。
- 本地检索不摄取附件正文；中文按单字切分，问法与邮件写法差异过大时依赖查询扩展，命中可能包含噪声。
- 云端模型与翻译服务的可用性、配额和输出准确性取决于所选服务；机器翻译仅用于辅助阅读。
