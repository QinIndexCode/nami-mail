## 简体中文

### 下载

请只下载本 Release 页面列出的 Windows `.exe` 安装程序。版本化 ZIP、JSON 更新清单、`latest.yml` 和 `.blockmap` 是发行与应用内更新使用的资源，不是手动安装包，不应自行解压或运行。

### 主要变化

- **首个正式的 External Mail v1 本机接口**（仅 Windows 桌面版）：`namimail` CLI 与本机 MCP stdio 接入，面向已配对的本地脚本与 MCP 客户端，保持本地优先、默认拒绝与最小权限。
- **本地检索**：邮件 RAG 页面与词法倒排索引持久化，重启后无需全量解密重建；第二路检索改为查询扩展——词法无结果时用模型生成同义/跨语言检索词重查同一份本地索引，不再需要部署嵌入模型，且**只把用户的问题发给模型，邮件正文不出本机**。
- **外部全文检索**：新增 `messages search`，支持账户/文件夹/时间范围与游标翻页，并报告本地同步进度以区分"没有匹配"与"尚未同步"。
- **邮件移动**：外部 CLI/MCP 的 `messages move` 现在可移动到同一账户下的任意文件夹，不再局限于归档与废纸篓。
- 邮件模板库、附件内联预览（PDF/图片渲染，Office 与文本提取只读预览）。

### 已修复（摘选，完整列表见变更日志）

- 隐私门：此前在"云端模型 + 未同意邮件内容上云"时按 Enter 仍会发送消息，现在键盘与按钮共用同一套可用性判定。
- 远程图片代理不再被重定向引导访问内网/本机地址；数据库迁移事务化，失败不会留下半迁移状态。
- 邮件列表滚动位置、批量操作后的乐观状态回滚、Agent 会话之间的引用串味、侧栏未读数跳回旧值、发件记录状态竞态等一批交互与同步问题。
- 阅读区宽度对齐 Gmail：HTML 邮件（如 600px 宽的新闻通讯模板）不再被挤窄到把词从中间折断。

### 更新与签名状态

- 本版本使用 **Ed25519 清单签名**作为更新信任根；**未进行 Authenticode 签名**，因此 Windows SmartScreen 可能显示"未知发布者"警告。请勿绕过 Windows 安全警告，只从本 Release 页面获取安装程序。
- 从 `0.2.3` 到 `0.3.0` 的**公共网络自动更新验收仍待完成**。本次发布不会在完成隔离验证前宣称在线升级链路已验收通过。
- 就地升级会保留现有本地数据；不会仅因本次更新而要求重新登录或重新授权账户。

### 已知限制

- 仅提供 Windows x64 桌面版。
- 本地检索不摄取附件正文；中文按单字切分，问法与邮件写法差异过大时（例如「报销」与「费用申请」）依赖查询扩展，命中可能包含噪声。
- 外部 v1 仅限邮件域：不暴露日历、记忆、设置更改、附件导出或转发。
- 云端模型与翻译服务的可用性、配额和输出准确性取决于所选服务；机器翻译仅用于辅助阅读。

## English

### Download

Download only the Windows `.exe` installer listed on this release page. The versioned ZIP, JSON update manifest, `latest.yml`, and `.blockmap` are distribution and in-app update resources, not manual installers — do not extract or run them yourself.

### Highlights

- **First formal External Mail v1 local interface** (Windows desktop only): the `namimail` CLI and a local MCP stdio entry point for paired local scripts and MCP clients, keeping local-first, default-deny, and least-privilege boundaries.
- **Local retrieval**: RAG pages and the lexical inverted index are persisted, so a restart no longer decrypts and rebuilds the whole mailbox. The second retrieval arm is now query expansion — when the keyword index finds nothing, the model suggests synonyms and cross-language terms that are searched against the same local index. No embedding model to deploy, and **only the user's question is sent to the model; mail bodies never leave the machine**.
- **External full-text search**: a new `messages search` command with account, folder, date-range and cursor filters that also reports local sync progress, so "no match" can be told apart from "not synced yet".
- **Move anywhere**: the external `messages move` command now accepts any folder of the same account, not just the archive and trash shortcuts.
- Mail template library and inline attachment preview (rendered PDF/images; read-only text extraction for Office documents and text files).

### Fixed (selected; see the changelog for the full list)

- Privacy gate: pressing Enter used to send a message even when a cloud provider had not been allowed to process mail content; the keyboard and the button now share one availability rule.
- The remote image proxy can no longer be redirected into loopback or private addresses, and database migrations run in a transaction so a failure cannot leave a half-applied schema.
- A batch of interaction and sync fixes: list scroll position, optimistic state rolled back during consecutive actions, mail references leaking between Agent conversations, the sidebar unread count jumping back, and delivery-record races.
- The reading pane now matches Gmail's width, so HTML mail (a 600px newsletter template, for example) is no longer squeezed until words break mid-way.

### Update and signing status

- This release uses an **Ed25519 manifest signature** as its update trust root and is **not Authenticode signed**, so Windows SmartScreen may show an "unknown publisher" warning. Do not bypass Windows security warnings; get the installer only from this release page.
- Public-network auto-update verification from `0.2.3` to `0.3.0` is **still pending**. This release does not claim the online upgrade path has been verified until the isolated verification is complete.
- In-place upgrades keep existing local data; no re-login or re-authorisation is required by this update alone.

### Known limitations

- Windows x64 desktop only.
- Local retrieval does not ingest attachment bodies. Chinese is indexed per character, so questions whose wording differs greatly from the mail (for example 「报销」 versus 「费用申请」) rely on query expansion and hits may include noise.
- External v1 is limited to the mail domain: no calendar, memory, settings changes, attachment export, or forwarding.
- Availability, quotas, and output accuracy of cloud models and translation services depend on the chosen service; machine translation is only a reading aid.
