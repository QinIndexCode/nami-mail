## 简体中文

### 升级前必读

**本次升级不可降级**：0.7.0 把数据库门禁从 v4 升到 v5（失败任务知悉、恢复尝试与自动回复工作队列），**升级并完成首次启动后，0.6.0 及更早版本会拒绝打开该数据库，无法降级回 0.6.0 或更早版本**。结构升级不删除邮件、账户、设置或密钥；如需保险请先整目录备份 `%APPDATA%\Nami Mail`（目录内的密钥与当前 Windows 用户绑定，换机或换用户无法直接使用）。就地升级无需重新登录或重新配置。

**0.6.0 用户可直接应用内升级**；**0.5.0 及更早版本**内置旧更新器无法升级，请手动安装 0.6.0 或直接安装 0.7.0。

请只下载本 Release 页面列出的 Windows `.exe` 安装程序；版本化 ZIP、JSON 清单、`latest.yml` 与 `.blockmap` 是发行和更新资源，不是手动安装包。

### 主要变化

- **数据与隐私**：口令加密的应用快照可导出与换机恢复；恢复前在隔离目录校验、确认后重启才启用，期间暂停未决的远端操作。
- **远程图片默认阻止**：可按单封加载、信任发件人或撤销，授权在服务端再次校验。
- **Markdown 写信与实时预览**：GFM 排版、快捷工具栏与快捷键、编辑/预览切换与最大化左右分屏；发送时编译为标准 `multipart/alternative`；收件人可快速搜索联系人与模板，联系人可一键写信。
- **密送（BCC）全链路独立贯通**：mailto → 撰写 → 草稿 → Agent 确认 → 加密请求 → SMTP；部分拒收持久显示，重试只选被拒地址。
- **失败任务可审阅、可重试、可对账**：逐项审阅与持久知悉、发送重试恢复正文/线程/附件；自动回复改为持久候选队列并对账出站结果，修复“排队即报成功”和单批超过 40 封被丢弃。
- **智能体更可控**：提供商支持 chat / decision 显式角色，接入 System One（Jev）判定模型与判定阈值；新增「智能体工具」页，列出 33 个内置工具的读写属性并实时反映当前执行权限。
- **日历与邮件细节**：ICS 时区/非法日期修复、日历游标完整加载、提醒按近期范围查询、本地日程导入导出保留身份；含 ICS 附件的邮件不再重复下载。
- **界面与安装体验**：Windows 窗口控件改为系统标准标题栏按钮；全局同心圆角对齐；AI 润色错误映射更清晰并保持书写模式；安装器不再闪现控制台，助手脚本携带 UTF-8 BOM。

### 更新与签名状态

- 沿用 **Ed25519 清单签名**作为更新信任根；**未进行 Authenticode 签名**，SmartScreen 可能显示“未知发布者”警告，请勿绕过，只从本 Release 页面获取安装程序。
- **真实旧版到新版的公开网络更新验收：待验证**（发布后按发布指南完成 0.6.0 → 0.7.0 真机更新验收）。
- 就地升级保留现有本地数据；不会要求重新登录或重新授权账户。

### 已知问题与限制

- **Outlook / Hotmail 暂无法在默认安装下登录（Issue #120）**：需 OAuth2 Client ID；可在 `%APPDATA%\Nami Mail\nami-mail.env` 配置 `NAMI_MAIL_MICROSOFT_OAUTH_CLIENT_ID` 临时使用。
- 远程图片默认阻止，但对某位发件人授权后，其唯一图片 URL 仍可用于观察打开行为；不需要时请撤销信任。
- 附件预览不支持旧版 Office 与 HEIC/TIFF/PSD（给出可下载说明）；PDF/扫描件需真机目视验收。
- 仅提供 Windows x64 桌面版；本地检索不摄取附件正文，中文按单字切分；云端服务取决于第三方提供商。

## English

### Read before upgrading

**This update cannot be downgraded**: 0.7.0 raises the database gate from v4 to v5 (failed-item acknowledgement, recovery attempts, and the auto-reply work queue). **After upgrading and completing the first launch, 0.6.0 and earlier refuse to open that database — you cannot roll back to 0.6.0 or older.** The schema upgrade deletes no mail, accounts, settings, or keys; back up `%APPDATA%\Nami Mail` first if you want a safety net (the key inside is bound to the current Windows user and is not portable across machines or users). In-place upgrades need no re-login or reconfiguration.

**0.6.0 users can update in-app**; **0.5.0 and earlier** bundle the old broken updater and must install 0.6.0 or 0.7.0 manually.

Download only the Windows `.exe` installer listed on this Release page; the versioned ZIP, JSON manifest, `latest.yml`, and `.blockmap` are distribution and update resources, not manual installers.

### Highlights

- **Data and privacy**: password-encrypted application snapshots export and restore on another machine; each restore is validated in isolation and activates only on a confirmed restart, pausing unfinished remote work meanwhile.
- **Remote images blocked by default**: load per message, trust a sender, or revoke at any time; authorization is re-checked on the server.
- **Markdown compose with live preview**: GFM formatting, toolbar and shortcuts, edit/preview switching, and a side-by-side split when maximized; sending compiles a standard `multipart/alternative` message; recipients suggest contacts and templates, and contacts can start a message in one click.
- **BCC carried separately end to end**: mailto → compose → draft → Agent confirmation → encrypted requests → SMTP; partial rejections stay visible and retries select only the rejected addresses.
- **Failed tasks you can review, retry, and reconcile**: item-by-item review with durable acknowledgement; send retries recover body, threading, and attachments; auto-reply runs on a durable candidate queue reconciled against outbound results, fixing "queued means sent" and batches over 40 being dropped.
- **More control over the assistant**: providers take explicit chat / decision roles, with the System One (Jev) decision model and a decision threshold; the new Agent Tools page lists all 33 built-in tools with read/write tags and mirrors the current execution level.
- **Calendar and mail details**: ICS time zones and invalid dates fixed, full cursor paging, reminders scoped to their own recent range, local event identity preserved across import/export, and no duplicate download of ICS attachments.
- **Interface and install experience**: Windows window controls become the standard caption band; concentric radii aligned on tokens; clearer AI-polish error mapping that preserves the writing mode; the installer no longer flashes a console and the helper script ships with a UTF-8 BOM.

### Update and Signing Status

- Keeps the **Ed25519 manifest signature** as the update trust root; **no Authenticode signature**, so SmartScreen may show an "unknown publisher" warning — do not bypass it, and obtain installers only from this Release page.
- **Real public-network upgrade acceptance from the previous version: pending verification** (run the documented 0.6.0 → 0.7.0 real-machine upgrade after release).
- In-place upgrades preserve existing local data; re-login or re-authorization is not required.

### Known Issues & Limitations

- **Outlook / Hotmail cannot sign in on a default install (Issue #120)**: requires an OAuth2 client ID; set `NAMI_MAIL_MICROSOFT_OAUTH_CLIENT_ID` in `%APPDATA%\Nami Mail\nami-mail.env` as a workaround.
- Remote images are blocked by default, but after trusting a sender their unique image URL can still observe opens; revoke that trust if unwanted.
- Attachment preview does not decode legacy Office or HEIC/TIFF/PSD (a download card explains); PDF/scans need human visual acceptance.
- Windows x64 desktop only; local search does not index attachment bodies and segments Chinese per character; cloud services depend on third-party providers.
