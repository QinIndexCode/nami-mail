## 简体中文

### 下载

请只下载本 Release 页面列出的 Windows `.exe` 安装程序。版本化 ZIP、JSON 更新清单、`latest.yml` 和 `.blockmap` 是发行与应用内更新使用的资源，不是手动安装包，不应自行解压或运行。

### 主要变化

- **会话线程补全**：Gmail 式跨目录会话归组。线程先由客户端对已加载邮件归组，缺失成员通过新端点补全（账户内按 RFC 头做双向传递闭包，排除草稿）；发送后自动补取线程。
- **引用自动折叠**：HTML 邮件顶层引用折叠为可点击展开的原生 `<details>`，纯文本折叠尾部 `> ` 引用块；净化、翻译与回复引用管线仍使用完整原文。
- **官网与文档站上线**：落地页与从 `docs/` 构建的文档页自动部署到 GitHub Pages，支持中英双语切换。

### 已修复（摘选，完整列表见变更日志）

- **Agent 撤回后立即重发的竞态**：会话回合持久化后服务端立即释放会话槽——此前收尾的首回合标题生成（慢供应商下最长约两分钟）会占住槽位，期间撤回后重发全部被拒绝，乐观消息从未落库；再次撤回报"消息不存在"，界面出现两条重复消息。前端现在也会在撤回遇"消息不存在"时采纳服务器快照对账，幽灵行立即消失，输入框保留待编辑重发的文本。
- **新邮件提示音"通知弹出但无声"**：主进程先播放、后弹横幅，播放失败自动回退为带系统音的通知并写入运行日志；启动后预热播放管线；设置页测试按钮与真实新邮件走完全相同的管线。
- **切换账户/文件夹/视图时的列表闪烁**、**自己发送邮件的方向展示**（按收件人渲染，不再按文件夹名猜测）、**Agent 网络搜索工具的解析脆弱性**（不再依赖搜索结果页 class 名）。

### 更新与签名状态

- 本版本使用 **Ed25519 清单签名**作为更新信任根；**未进行 Authenticode 签名**，因此 Windows SmartScreen 可能显示"未知发布者"警告。请勿绕过 Windows 安全警告，只从本 Release 页面获取安装程序。
- 从 `0.3.0` 到 `0.4.0` 的**公共网络自动更新验收仍待完成**。本次发布不会在完成隔离验证前宣称在线升级链路已验收通过。
- 就地升级会保留现有本地数据；不会仅因本次更新而要求重新登录或重新授权账户。

### 已知限制

- 仅提供 Windows x64 桌面版。
- 云端模型与翻译服务的可用性、配额和输出准确性取决于所选服务；机器翻译仅用于辅助阅读。
- 本地检索不摄取附件正文；中文按单字切分，问法与邮件写法差异过大时依赖查询扩展，命中可能包含噪声。

## English

### Download

Download only the Windows `.exe` installer listed on this release page. The versioned ZIP, JSON update manifest, `latest.yml`, and `.blockmap` are distribution and in-app update resources, not manual installers — do not extract or run them yourself.

### Highlights

- **Conversation thread completion**: Gmail-style grouping across folders. Threads are grouped client-side over the loaded set first; missing members are completed through a new endpoint (a bidirectional transitive closure over RFC headers within the account, drafts excluded), and threads are refetched automatically after sending.
- **Quote auto-folding**: top-level quoted blocks in HTML mail collapse into native clickable `<details>` elements, and trailing `> ` quote blocks collapse in plain text. Sanitizing, translation, and reply-quote pipelines still use the full body.
- **Website and documentation site**: a landing page plus docs pages built from `docs/`, deployed automatically to GitHub Pages with an English/Chinese language switch.

### Fixed (selected; see the changelog for the full list)

- **The revoke-then-resend race in the Agent**: the server now releases the conversation slot as soon as a turn is persisted. Previously the first-turn title generation tail (up to ~two minutes on a slow provider) kept holding the slot, every resend after a revoke was refused and the optimistic message was never persisted; revoking it again reported "message not found" and the UI showed two identical rows. The client also adopts the server snapshot when a revoke hits "not found" — phantom rows disappear immediately while the refilled composer text is kept for editing and resending.
- **The "banner pops up but no sound" problem with the new-mail notification sound**: the main process plays the sound first and shows the banner afterwards; any playback failure falls back to a system-sound notification and is logged. The playback pipeline is warmed up at startup, and the Settings test buttons use exactly the same pipeline as a real alert.
- **List flicker when switching account/folder/view**, **direction display for self-sent mail** (rendered by recipient instead of guessing from the folder name), and **the fragile parsing in the Agent's web-search tool** (no longer dependent on result-page class names).

### Update and signing status

- This release uses an **Ed25519 manifest signature** as its update trust root and is **not Authenticode signed**, so Windows SmartScreen may show an "unknown publisher" warning. Do not bypass Windows security warnings; get the installer only from this release page.
- Public-network auto-update verification from `0.3.0` to `0.4.0` is **still pending**. This release does not claim the online upgrade path has been verified until the isolated verification is complete.
- In-place upgrades keep existing local data; no re-login or re-authorisation is required by this update alone.

### Known limitations

- Windows x64 desktop only.
- Availability, quotas, and output accuracy of cloud models and translation services depend on the chosen service; machine translation is only a reading aid.
- Local retrieval does not ingest attachment bodies. Chinese is indexed per character, so questions whose wording differs greatly from the mail rely on query expansion and hits may include noise.
