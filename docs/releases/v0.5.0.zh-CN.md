# Nami Mail 0.5.0

[简体中文](v0.5.0.zh-CN.md) | [English](v0.5.0.en.md)

Nami Mail 0.5.0 是一个里程碑式的重要版本升级：引入全栈本地日历体系（月视图浏览、事件管理、ICS 导入导出与邮件邀请横幅直达会议）、端到端多模态大模型接入（图片、音频、视频与 PDF 文档上下文附件）、全套 UI 设计系统与视觉体验重构（恢复圆角 Token、同心圆角法则、侧边栏滚动条隐藏、全宽 Markdown 表格与半透明磨砂骨架屏）、账户后台同步状态实时感知、Agent 流式输出与工具调用深度加固、以及桌面端自动更新下载管道稳定性优化。

## 下载

请只使用匹配 GitHub Release 页面列出的 Windows `.exe` 安装程序。版本化 ZIP、JSON 更新清单、`latest.yml` 和 `.blockmap` 用于发行与应用内更新，不是手动安装包。

## 更新与签名状态

- 发布前验收：CI 全量验证通过（typecheck / lint / 单元与集成测试 / e2e / desktop smoke / 依赖审计）；release job 在打包后运行 package smoke 并校验草稿资产完整性，通过后转正发布。
- `0.5.0` Windows 安装程序采用 Ed25519 清单签名作为更新信任根；未进行 Authenticode 签名。Windows SmartScreen 可能显示未知发布者警告。请勿绕过 Windows 安全警告，只应从本 Release 页面获取安装程序。
- 就地升级会保留现有本地数据；不会仅因本次更新而要求重新登录或重新授权账户。

## 本次更新

- **全栈本地日历与邮件会议邀请体系（Calendar）**：
  - 新增完整内置日历域：提供月视图浏览、日程事件创建、编辑、删除与搜索；
  - 邮件日历邀请横幅：阅读含 `.ics` 附件的邮件时自动解析并展示首个事件的主题、时间、地点，智能识别腾讯会议、Zoom、飞书、钉钉、Teams、Google Meet 等主流会议链接直达入会；
  - ICS 导入与 UID 原地去重：支持导入与导出 ICS 文件；追加导入同一份日历时按 ICS UID 原地更新（upsert），绝不产生重复日程；
  - 附件解析容量守卫：横幅解析结果按邮件分片缓存避免重复拉取；严格限制 10MB 附件上限与 5 万行解析防护，防御解压炸弹；
  - 事件开始前 15 分钟应用内提醒（toast）直达日历，支持去重与通知联动；
  - 日历数据完全保存在本机 SQLite 数据库中，不向任何第三方或远端 CalDAV 同步。
- **多模态大模型接入与端到端附件传输（Multimodal）**：
  - 在 Agent 模型提供商配置中新增独立的输入模态开关，支持显式开启图片（Image）、音频（Audio）、视频（Video）与 PDF 文档处理能力；
  - 动态文件过滤器：Composer 附件选择器自适应感知当前会话模型的可用模态，过滤非允许类型并展示专用类别文件图标 Badge；
  - 协议规范化：服务端端到端适配 OpenAI Chat、OpenAI Responses、Anthropic Claude 与 Google Gemini 的原生多模态数据结构，提供规范的 Base64 与多媒体传输；
  - 严格向下兼容：历史模型与未配置多模态的模型严格降级为纯文本，防止因附件调用无多模态能力的模型而报错。
- **全套 UI 设计系统重构与视觉体验升级**：
  - 恢复全局设计系统软圆角 Token（`--radius-sm: 8px`、`--radius-md: 12px`、`--radius-lg: 20px`），消除按钮、邮件条目、卡片的不协调硬边；
  - 贯彻同心圆角法则（$R_{inner} = R_{outer} - padding$），解决 Agent 启动徽标与顶栏标题徽标内角畸变；
  - 隐藏侧边栏原生滚动条（`scrollbar-width: none`），保留原生触控与滚轮平滑滚动并杜绝布局跳动；
  - 全面消除历史紫色高光，统一采用单色调极简中性视觉，模态弹窗表头精简为纯净单行标题；
  - 模态弹窗采用 Body Portal 传送门渲染，彻底消除多层 Dialog 嵌套时的 z-index 与包含块陷阱；
  - 修复 Agent 历史记录擦除滚动导致整体页面上移的视口偏移缺陷，隔离至容器级精准滚动；
  - 封禁已结束历史会话误触发思考态的问题；
  - Agent Markdown 表格全宽排版优化（包裹 `.agent-table-wrap`），消除右侧空白断层；
  - 对话记录加载骨架屏用户方重构为半透明磨砂气泡配对流光扫掠动画（`0.25 ~ 0.65`），对齐助手骨架质感。
- **账户同步进行时态感知**：
  - 账户状态新增运行时 `syncing` 标志（内存同步锁，非数据库列），同步进行中侧边栏即时显示"正在同步…"脉冲状态点与说明，不再滞留上一轮的最终状态；
  - 优化文件夹切换与静默轮询的并发时序保护，杜绝跨文件夹数据覆盖与网络争用。
- **Agent 流式鲁棒性与工具加固**：
  - 供应商遇畸形 arguments、不完整调用或缺少参数时自动降级为空对象并交由校验拒绝，错误回喂模型触发自愈重试；
  - 上下文预算超出警戒线时智能剪枝超长工具结果，自动压缩折叠多轮历史会话；
  - 增加工具前置处理器与会话树滚动保护，保障长文本流式传输稳定。
- **架构解耦与工程治理**：
  - 将原 4355 行超大单体 `App.tsx` 拆分为 8 个领域 hooks 与子组件，提升系统长期维护性；
  - 全面清理 ESLint 告警，提升满核并发测试超时宽容度，根治 CI flaky 偶现超时。
- **桌面端自动更新管道稳定性**：
  - 下载更新管道拥有独立写入生命周期管理，背压释放时安全解绑错误监听器；
  - 原子重命名落盘后再提交偏好，杜绝进程意外关闭导致损坏安装包残留。

## 安全与范围

- 本地优先原则始终如一：日历、多模态解析及会话数据均完全保存在本地；
- 云端模型必须显式开启邮件内容授权后才可在授权范围内检索；
- 更新信任根保持不变：GitHub 更新资产继续使用 Ed25519 清单签名校验。

## 已知问题与限制

- **Outlook / Hotmail 账户在默认安装下暂无法直接登录（跟踪 Issue #120）**：微软已关闭密码认证强制采用 OAuth2，由于官方构建尚未内置 Azure OAuth Client ID，当前微软登录暂不可用；可在 `%APPDATA%\Nami Mail\nami-mail.env` 配置 `NAMI_MAIL_MICROSOFT_OAUTH_CLIENT_ID` 环境变量临时使用。
- **平台支持**：当前仅提供 Windows x64 桌面版。
- **搜索与检索**：本地检索不摄取附件正文；中文按单字切分。
- **第三方服务**：云端模型与翻译服务可用性取决于所选第三方服务提供商。
