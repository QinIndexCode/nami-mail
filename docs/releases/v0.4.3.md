## 简体中文

### 下载

请只下载本 Release 页面列出的 Windows `.exe` 安装程序。版本化 ZIP、JSON 更新清单、`latest.yml` 和 `.blockmap` 是发行与应用内更新使用的资源，不是手动安装包，不应自行解压或运行。

### 主要变化

- **全量设置界面 UI/UX 与美学重构**：去除各面板冗余的静态说明文本与大段副标题，统一采用内联悬停图标展示帮助提示，大幅精简视觉元素；优化所有信息图标与文本标签的水平垂直居中对齐；统一所有复制图标的点击对勾反馈动效；解耦模块化样式表（`settings.css`、`agent.css`、`modals.css` 等）；消除外露 MCP 滚动条导致的弹窗宽度抖动。
- **外部连接体系（内置 MCP / 外露 MCP / 外部 CLI）清晰重构与跨平台 IPC 抽象**：严格划分内置 MCP 客户端、本地外露 MCP 宿主服务与外部 CLI；完善外露服务管理（启动/停止/重启）、配置快速复制与权限等级；新增 CLI 配对令牌撤销能力；抽象统一的跨平台本地 IPC 传输层，同时支持 Windows 命名管道与 POSIX Unix Domain Sockets，并执行严格的文件权限与属主校验。
- **邮件自动回复链接过滤与 Token 压缩**：在送交大模型判定邮件是否需要回复前，自动过滤与精简 HTML 链接、Markdown 链接、原生跟踪/广告长 URL 及 Base64 内联图片，提取精简域名并归一化退订链接，大幅降低无谓 Token 消耗与模型耗时。
- **模型上下文预算估计、工具结果剪枝与自动历史压缩**：支持配置模型上下文大小与最大输出；Agent 循环全周期自动预算估计；触及警戒线时对工具结果执行智能剪枝，并自动压缩历史多轮对话。
- **自动回复沙盒模拟器（Dry-Run）与动效优化**：新增零副作用沙盒调试工具，支持自定义测试邮件或快速载入真实样本，端到端可视化展示链接清洗 Token 节约、规则匹配判定、大模型思考理由及拟定回复草稿；引入贝塞尔平滑入场过渡动画与脉冲加载骨架态。
- **打字机流式渐入与草稿视觉优化**：拟定回复草稿展示接入自适应速率打字机流式渐入效果，长文本在 1.5 秒内平滑收敛展现；增加纯 CSS 闪烁呼吸光标、一键跳过“完整显示”控制与减弱动态偏好（`prefers-reduced-motion`）瞬间直出支持。
- **系统端到端性能指标可观测性完善**：沙盒模拟执行全流程接入高精度计时测量，结构化拆解初筛耗时、Token 压缩耗时、范围规则耗时与模型调用耗时；结果卡片顶栏展示轻量微型耗时胶囊 Badge，并深度集成到前端性能遥测系统中。

### 更新与签名状态

- 本版本使用 **Ed25519 清单签名**作为更新信任根；**未进行 Authenticode 签名**，因此 Windows SmartScreen 可能显示"未知发布者"警告。请勿绕过 Windows 安全警告，只从本 Release 页面获取安装程序。
- 就地升级会保留现有本地数据；不会仅因本次更新而要求重新登录或重新授权账户。

### 已知限制

- 仅提供 Windows x64 桌面版。
- 本地检索不摄取附件正文；中文按单字切分。
- 云端模型与翻译服务可用性取决于所选第三方服务提供商。

## English

### Download

Download only the Windows `.exe` installer listed on this release page. The versioned ZIP, JSON update manifest, `latest.yml`, and `.blockmap` are distribution and in-app update resources, not manual installers — do not extract or run them yourself.

### Highlights

- **Settings UI/UX & Aesthetic Overhaul**: Removed wall-of-text static subtitles across all settings panels, switching to elegant hover tooltips; standardized baseline vertical alignment for helper icons and labels; unified copy button checkmark micro-interactions; modularized CSS; and eliminated layout shifts when toggling exposed MCP subpanels.
- **External Connections Clarification & Cross-Platform IPC Abstraction**: Strictly segregated internal built-in MCP client tools, locally exposed MCP servers, and external `namimail` CLI tool suites; added cross-platform IPC transport abstraction supporting both Windows Named Pipes and POSIX Unix Domain Sockets with strict UID/0600 permission checks.
- **Auto-Reply Link Sanitization & Token Preservation**: Automatically sanitizes tracking links, Markdown links, and base64 images into compact tags prior to LLM evaluation, saving significant prompt tokens.
- **Context Budget Estimation, Tool Pruning & Auto History Compression**: Added context window and max output settings, dynamic token budget tracking, threshold-triggered tool result pruning, and automatic multi-turn history compression.
- **Auto-Reply Dry-Run Simulator (Sandbox) & Visual Polish**: Zero-side-effect sandbox for testing auto-reply pipelines with custom inputs or inbox samples, displaying token savings, rule matches, LLM reasons, and drafted previews, polished with smooth cubic-bezier entry transitions and pulse loading cards.
- **Typewriter Streaming Animation & Draft Visuals**: Progressive draft stream-in with length-adaptive cadence (<1.5s), CSS breathing cursor, instant-reveal skip control, and `prefers-reduced-motion` fallback.
- **End-to-End Performance Metrics & Latency Telemetry**: Implemented high-precision stage timings (sanitization, screening, scope, LLM latency), surfaced compact latency capsule badges on results, and integrated telemetry into `perfTelemetry`.

### Update and signing status

- Pre-release validation: CI validation passed in full.
- The `0.4.3` Windows installer is not Authenticode signed. Windows SmartScreen may show an "unknown publisher" warning.
- In-place upgrades keep existing local data.

### Known limitations

- Windows x64 desktop only.
- Local retrieval does not ingest attachment bodies.
- Availability, quotas, and output accuracy of cloud models depend on the chosen third-party provider.
