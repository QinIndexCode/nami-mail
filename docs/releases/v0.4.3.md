## 简体中文

### 下载

请只下载本 Release 页面列出的 Windows `.exe` 安装程序。版本化 ZIP、JSON 更新清单、`latest.yml` 和 `.blockmap` 是发行与应用内更新使用的资源，不是手动安装包，不应自行解压或运行。

### 主要变化

- **邮件文件夹导航模式（Tree 树状模式 / Focus 专注模式切换）**：支持在层级树状展开与扁平专注模式间一键切换，优化多层级文件夹折叠与导航体验。
- **账户管理邮箱地址快速复制**：支持在账户列表中一键复制邮箱地址并配备平滑对勾动效。
- **Agent 输出稳定性修复与视觉呈现优化**：彻底修复流式输出因切会话或重渲染偶现丢弃尾部未排干文本（queued deltas）的问题；优化工具卡片、进度提示与状态动效；回复草稿接入自适应速率打字机流式渐入（`useTypewriter`）与呼吸光标。
- **自动回复双模型独立配置与沙盒模拟器（Dry-Run）**：支持独立配置判定初筛模型与回复生成模型；新增零副作用沙盒模拟器，直观展示链接清洗节约量、规则匹配与草稿预览；自动清洗长链接与 Base64 图片，显著节约 Prompt Token。
- **邮件过滤规则功能修复**：修复过滤规则在多条件判定与动作执行时的逻辑与状态同步异常，确保过滤动作可靠生效。
- **添加邮箱向导流程与交互提示优化**：优化添加账户向导流程与主流邮箱授权提示，规范输入校验与错误反馈。
- **全量设置界面 UI/UX 与美学重构**：消除文字墙与冗余静态副标题，统一内联悬停问号提示；优化标签居中对齐、控件高度（32px）与复制对勾动效；解耦模块化样式表（`settings.css` 等）；消除外露 MCP 滚动条抖动。
- **外部连接体系清晰重构与跨平台 IPC 抽象**：严格划分内置 MCP、外露 MCP 服务与外部 CLI；完善外露服务管理、配置复制与 CLI 令牌撤销；抽象统一跨平台 IPC 传输层（支持 Windows 命名管道与 Unix Domain Sockets），严格校验属主与 0600 权限。
- **模型上下文预算估计、工具结果剪枝与自动历史压缩**：支持配置上下文与输出预算大小；Agent 循环全周期自动预算跟踪；超阈值智能剪枝长工具结果，自动折叠压缩多轮历史消息。
- **系统端到端性能指标可观测性完善**：沙盒模拟执行全链路高精度分段耗时测量；结果顶栏展示微型耗时胶囊 Badge；深度集成前端性能遥测。

### 更新与签名状态

- 本版本使用 **Ed25519 清单签名**作为更新信任根；**未进行 Authenticode 签名**，因此 Windows SmartScreen 可能显示"未知发布者"警告。请勿绕过 Windows 安全警告，只从本 Release 页面获取安装程序。
- 就地升级会保留现有本地数据；不会仅因本次更新而要求重新登录或重新授权账户。

### 已知问题与限制

- **Outlook / Hotmail 账户在默认安装下暂无法直接登录（跟踪 Issue #120）**：微软已关闭密码认证强制采用 OAuth2，由于官方构建尚未内置 Azure OAuth Client ID，当前微软登录暂不可用；可在 `%APPDATA%\Nami Mail\nami-mail.env` 配置 `NAMI_MAIL_MICROSOFT_OAUTH_CLIENT_ID` 环境变量临时使用，后续版本将内置解决。
- 仅提供 Windows x64 桌面版。
- 本地检索不摄取附件正文；中文按单字切分。
- 云端模型与翻译服务可用性取决于所选第三方服务提供商。

## English

### Download

Download only the Windows `.exe` installer listed on this release page. The versioned ZIP, JSON update manifest, `latest.yml`, and `.blockmap` are distribution and in-app update resources, not manual installers — do not extract or run them yourself.

### Highlights

- **Mail Folder Navigation Modes (Tree Mode & Focus Mode)**: One-click toggle between hierarchical tree view and focused flat view, optimizing nested folder navigation.
- **Account Email Address Copy**: One-click copy button for account email addresses with smooth checkmark micro-interaction.
- **Agent Output Reliability & Visual Polish**: Fixed text loss caused by un-drained queued deltas during conversation switches or re-renders; polished tool execution cards and chips; added adaptive typewriter stream-in (`useTypewriter`) with blinking cursor and instant skip.
- **Auto-Reply Dual-Model Separation & Dry-Run Sandbox**: Independent configuration for screening vs drafting models; added zero-side-effect sandbox simulator to inspect token savings, rule matches, and drafts; built-in link sanitization and token reduction.
- **Mail Filter Rules Bugfix**: Resolved condition evaluation and state synchronization anomalies in mail filter rules, ensuring filtering actions execute reliably.
- **Add-Account Guidance Polish**: Refined account setup wizard and authentication guidance for major mail providers with standardized validation feedback.
- **Settings UI/UX & Aesthetic Overhaul**: Eliminated wall-of-text static subtitles with inline hover tooltips; standardized alignment, 32px control heights, and copy checkmark feedback; modularized stylesheets; eliminated scrollbar layout shifts.
- **External Connections Clarification & Cross-Platform IPC Abstraction**: Segregated built-in MCP, exposed MCP servers, and external CLI; added cross-platform IPC transport abstraction (Windows Named Pipes & Unix Domain Sockets) with strict UID/0600 security checks.
- **Context Budget Estimation, Tool Pruning & Auto History Compression**: Added context window and max output settings, dynamic token budget tracking, threshold-triggered tool result pruning, and automatic multi-turn history compression.
- **End-to-End Performance Metrics & Latency Telemetry**: Implemented high-precision stage timings (sanitization, screening, scope, LLM latency), surfaced latency capsule badges, and integrated telemetry.

### Update and signing status

- Pre-release validation: CI validation passed in full.
- The `0.4.3` Windows installer is not Authenticode signed. Windows SmartScreen may show an "unknown publisher" warning.
- In-place upgrades keep existing local data.

### Known Issues & Limitations

- **Outlook / Hotmail Sign-in Currently Unavailable on Clean Installs (Tracking Issue #120)**: Microsoft requires OAuth2 for Outlook.com; without an embedded Azure OAuth client ID, Sign in with Microsoft is disabled out of the box. Workaround: set `NAMI_MAIL_MICROSOFT_OAUTH_CLIENT_ID` in `%APPDATA%\Nami Mail\nami-mail.env`.
- Windows x64 desktop only.
- Local retrieval does not ingest attachment bodies.
- Availability, quotas, and output accuracy of cloud models depend on the chosen third-party provider.
