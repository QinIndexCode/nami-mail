# Nami Mail 0.4.1

[简体中文](v0.4.1.zh-CN.md) | [English](v0.4.1.en.md)

Nami Mail 0.4.1 is an ergonomics and visual polish release: it refactors the agent sensitive-operation confirmation card docking and collapse animation above the composer, introduces BIMI brand avatar resolution with secure caching, enables drag-and-drop attachment uploads and clipboard image pasting, and suppresses redundant translation banners.

## Download

Download only the Windows `.exe` installer listed on this release page. The versioned ZIP, JSON update manifest, `latest.yml`, and `.blockmap` are distribution and in-app update resources, not manual installers — do not extract or run them yourself.

## Update and signing status

- Pre-release validation: CI validation passed in full (typecheck, lint, unit & integration tests, e2e, desktop smoke, and dependency audit); the release job signs, packages, runs package smoke, and verifies draft assets before promoting the release to public.
- The `0.4.1` Windows installer is not Authenticode signed. Windows SmartScreen may show an "unknown publisher" warning. Do not bypass Windows security warnings; get the installer only from this release page.
- In-place upgrades keep existing local data; no re-login or re-authorization is required by this update alone.

## Highlights

- **Agent Confirmation Card Physical Docking & Smooth Collapse**:
  - Re-architected the docking between the sensitive-action confirmation card and the composer: `.agent-composer` now renders a solid panel background (`var(--panel-solid)`) acting as an opaque occlusion surface, tucking the card bottom edge 14px underneath via slot negative margins.
  - Eliminated the floating gap and border artifacts previously caused by the gradient fade mask.
  - Added 24px bottom button safe padding to avoid blocking action buttons; synchronized grid row heights with negative margins over bezier curves for seamless expand and collapse animations.
- **BIMI Brand Avatar Support**:
  - Resolve and display enterprise sender SVG brand avatars according to DMARC/BIMI standards, improving visual brand verification.
  - Hardened with strict SVG sanitization, size normalization, two-tier memory and disk caching, and TTL expiry.
- **Compose Attachment Drag & Drop and Clipboard Image Paste**:
  - Drag and drop files directly onto the compose dialog with a clear dashed drop zone indicator.
  - Paste clipboard screenshots and images directly into the message body using `Ctrl+V`.
- **Redundant Translation Banner Suppression**:
  - Detect message body language characteristics to hide the "Translate to current language" banner when content already matches the client language, reducing visual clutter.
- **Windows CI Smoke Stability**:
  - Raised the window-loaded startup ceiling on GitHub Actions runners to prevent false alarms under heavy host loads.

## Security & Scope

- This release introduces no new outbound attack surface: no new open network ports, and mail data remains strictly on your local device.
- BIMI icon fetching is strictly sanitized and sandboxed without executing inline scripts or remote external resource loads.
- Update trust root remains unchanged: GitHub ZIP update assets are verified with Ed25519 manifest signatures against the embedded public key.
- Local-first boundary preserved: credentials remain encrypted on your device.

## Known limitations

- Windows x64 desktop only.
- Local retrieval does not ingest attachment bodies. Chinese is indexed per character, so questions whose wording differs greatly from the mail rely on query expansion and hits may include noise.
- Availability, quotas, and output accuracy of cloud models and translation services depend on the chosen service; machine translation is only a reading aid.
