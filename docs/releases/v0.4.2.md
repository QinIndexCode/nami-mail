## 简体中文

### 下载

请只下载本 Release 页面列出的 Windows `.exe` 安装程序。版本化 ZIP、JSON 更新清单、`latest.yml` 和 `.blockmap` 是发行与应用内更新使用的资源，不是手动安装包，不应自行解压或运行。

### 主要变化

- **Windows 安装程序自定义路径生效与覆写缺陷修复**：彻底修复了在安装向导中选择自定义路径后实际仍被覆写安装至系统盘默认 C 盘目录的问题。调整宏执行时序，遵循生命周期标准在模式确定后再展示目录选择，并在构建配置中显式声明 `allowToChangeInstallationDirectory: true`。
- **覆盖安装与升级安装历史路径自动探测与记忆恢复**：修复重复安装或升级时非系统盘旧路径丢失、被重置回 C 盘的缺陷。新增 `preInit` 阶段的多源探测恢复宏（`namiRecoverExistingInstallLocation`），交叉反解专有注册表项、Windows 卸载记录（`UninstallString`、`DisplayIcon`、`InstallLocation`）中的真实安装路径，并双重写入注册表保护后续升级。
- **Agent 审批卡片物理插槽吸附与平滑折叠**：重构审批卡片在输入框正上方的吸附咬合层级，输入框应用实体背景遮挡卡片底边，配合 `-14px` 负边距抽屉插槽咬合，消除虚边与悬浮断层感；加入 24px 底部安全缓冲并应用同步贝塞尔缓动，收起与展开顺畅平滑。
- **BIMI 官方发件人品牌图标支持**：支持从 DMARC/BIMI 规范解析企业官方发件人 SVG 品牌图标，增强官方验证邮件的视觉辨识度；具备严格的 SVG 安全净化、尺寸规整、内存与磁盘双级缓存及 TTL 过期保护机制。
- **写信窗口附件拖拽与截图粘贴**：支持将本地文件直接拖拽添加为附件，具备清晰的虚线投放反馈遮罩；正文编辑区支持剪贴板图片 `Ctrl+V` 直接粘贴上传。
- **同语言邮件翻译提示抑制**：智能探测邮件正文语言特征，当语言与客户端当前界面语言一致时，默认不显示多余的“翻译为当前语言”横幅，消除视觉干扰。

### 更新与签名状态

- 本版本使用 **Ed25519 清单签名**作为更新信任根；**未进行 Authenticode 签名**，因此 Windows SmartScreen 可能显示"未知发布者"警告。请勿绕过 Windows 安全警告，只从本 Release 页面获取安装程序。
- 就地升级会保留现有本地数据；不会仅因本次更新而要求重新登录或重新授权账户。

### 已知限制

- 仅提供 Windows x64 桌面版。
- 云端模型与翻译服务的可用性、配额和输出准确性取决于所选服务；机器翻译仅用于辅助阅读。
- 本地检索不摄取附件正文；中文按单字切分，问法与邮件写法差异过大时依赖查询扩展，命中可能包含噪声。

## English

### Download

Download only the Windows `.exe` installer listed on this release page. The versioned ZIP, JSON update manifest, `latest.yml`, and `.blockmap` are distribution and in-app update resources, not manual installers — do not extract or run them yourself.

### Highlights

- **Windows Installer Custom Path Enforcement & Overwrite Bug Fix**: Fixed a critical defect where custom installation paths selected in the setup wizard were silently overridden back to the C: drive. Adjusted the wizard sequencing to display directory selection after the install mode is established, and explicitly enabled `allowToChangeInstallationDirectory: true`.
- **Existing Installation Path Recovery on Upgrade & Reinstall**: Fixed an issue where running the installer again or upgrading in-place failed to detect existing installations located on non-system drives. Added a multi-source recovery macro (`namiRecoverExistingInstallLocation`) in the `preInit` hook to extract and normalize the true installation path from dedicated registry keys and Windows uninstall entries, with dual registration of `InstallLocation` for subsequent updates.
- **Agent Confirmation Card Physical Docking & Smooth Collapse**: Re-architected the docking between the sensitive-action confirmation card and the composer: `.agent-composer` now renders a solid panel background (`var(--panel-solid)`) acting as an opaque occlusion surface, tucking the card bottom edge 14px underneath via slot negative margins; eliminated floating gap and border artifacts, provided 24px bottom button safe padding, and synchronized grid row heights with negative margins over bezier curves for seamless expand and collapse animations.
- **BIMI Brand Avatar Support**: Resolve and display enterprise sender SVG brand avatars according to DMARC/BIMI standards, improving visual brand verification. Hardened with strict SVG sanitization, size normalization, two-tier memory and disk caching, and TTL expiry.
- **Compose Attachment Drag & Drop and Clipboard Image Paste**: Drag and drop files directly onto the compose dialog with a clear dashed drop zone indicator; paste clipboard screenshots and images directly into the message body using `Ctrl+V`.
- **Redundant Translation Banner Suppression**: Detect message body language characteristics to hide the "Translate to current language" banner when content already matches the client language, reducing visual clutter.

### Update and signing status

- This release uses an **Ed25519 manifest signature** as its update trust root and is **not Authenticode signed**, so Windows SmartScreen may show an "unknown publisher" warning. Do not bypass Windows security warnings; get the installer only from this release page.
- In-place upgrades keep existing local data; no re-login or re-authorisation is required by this update alone.

### Known limitations

- Windows x64 desktop only.
- Availability, quotas, and output accuracy of cloud models and translation services depend on the chosen service; machine translation is only a reading aid.
- Local retrieval does not ingest attachment bodies. Chinese is indexed per character, so questions whose wording differs greatly from the mail rely on query expansion and hits may include noise.
