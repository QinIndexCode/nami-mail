# Nami Mail 0.4.3

[简体中文](v0.4.3.zh-CN.md) | [English](v0.4.3.en.md)

Nami Mail 0.4.3 是一个聚焦于系统设置交互美学升级、Agent 输出稳定性与视觉优化、邮件文件夹导航、双模型自动回复流水线及沙盒测试的重要版本：邮件文件夹新增 Tree 树状模式与 Focus 专注模式切换；彻底修复 Agent 流式输出时渲染丢失未排干文本的问题并全面优化视觉呈现；支持为自动回复单独配置判断初筛模型与回复生成模型；修复邮件过滤规则多条件判定异常；新增零副作用的自动回复沙盒模拟器；优化添加邮箱向导流程与错误提示；引入模型上下文窗口与最大输出预算管理、超长工具结果剪枝与历史会话自动压缩；并对外部连接体系（内置 MCP、外露 MCP 服务与外部 CLI）进行了跨平台 IPC 协议抽象与架构梳理。

## 下载

请只使用匹配 GitHub Release 页面列出的 Windows `.exe` 安装程序。版本化 ZIP、JSON 更新清单、`latest.yml` 和 `.blockmap` 用于发行与应用内更新，不是手动安装包。

## 更新与签名状态

- 发布前验收：CI 全量验证通过（typecheck / lint / 单元与集成测试 / e2e / desktop smoke / 依赖审计）；release job 在打包后运行 package smoke 并校验草稿资产完整性，通过后转正发布。
- `0.4.3` Windows 安装程序未进行 Authenticode 签名。Windows SmartScreen 可能显示未知发布者警告。请勿绕过 Windows 安全警告，只应从本 Release 页面获取安装程序。
- 就地升级会保留现有本地数据；不会仅因本次更新而要求重新登录或重新授权账户。

## 本次更新

- **邮件文件夹导航模式（Tree 树状模式 / Focus 专注模式切换）**：
  - 新增邮件文件夹在层级树状展开（Tree 模式）与专注扁平化视口（Focus 模式）之间的一键切换；
  - 针对多层级与深度嵌套文件夹提供更直观的折叠与导航体验，适应不同邮件整理习惯。
- **账户管理邮箱地址快速复制**：
  - 在账户管理列表中支持一键复制当前邮箱地址，并配备平滑对勾过渡反馈微动效。
- **Agent 输出稳定性修复与视觉呈现优化**：
  - 彻底修复 Agent 在流式输出过程中因切换会话或组件重新渲染偶现丢失尾部未排干文本（queued deltas）的问题，保障长文本与复杂格式内容完整交付；
  - 优化 Agent 输出界面视觉效果与排版，改进工具调用状态卡片、搜索进度微胶囊与状态提示；
  - 拟定回复草稿展示接入自适应打字机流式渐入效果（`useTypewriter`）与纯 CSS 呼吸闪烁光标，支持一键跳过与减弱动态偏好（`prefers-reduced-motion`）。
- **自动回复双模型独立配置与沙盒模拟器（Dry-Run）**：
  - 增加对自动回复「判定初筛模型」与「回复生成模型」的独立拆分配置能力，允许选用高响应/低成本模型快速过滤无价值邮件，并使用高智能大模型拟定优质回复草稿；
  - 新增零副作用的「自动回复沙盒模拟器」，支持输入任意测试邮件或从收件箱载入真实样本，端到端可视化展示链接清洗 Token 节约、过滤规则匹配、大模型决策理由及拟定草稿预览；
  - 自动过滤与精简邮件长链接、跟踪参数与 Base64 内联图片，智能归一化退订链接，大幅节约 Prompt Token 并降低模型处理延迟。
- **邮件过滤规则功能修复**：
  - 修复邮件过滤规则（Filter Rules）在复杂多条件判定与动作执行时的逻辑与状态同步异常，确保各类发件人、主题及正文过滤规则精准可靠生效。
- **添加邮箱向导流程与交互提示优化**：
  - 优化添加邮箱账户时的向导流程，对主流邮箱提供更清晰的配置引导与授权提示；
  - 规范输入验证状态与错误反馈逻辑，避免半输入状态下的误导性密码框或无效死胡同提示。
- **全量设置界面 UI/UX 与美学重构**：
  - 彻底去除各设置面板中冗余的静态说明文本与大段副标题，统一采用内联悬停问号图标展示帮助提示，消除文字墙，界面更清爽紧凑；
  - 优化所有信息图标与文本标签的水平垂直居中基准线对齐，统一控件高度（32px）与圆角视觉韵律；
  - 统一设置界面所有复制图标的点击交互反馈动效，采用对齐邮箱管理面板中的对勾微交互过渡；
  - 彻底拆分重构原单体超大 `styles.css`，解耦为专有模块化样式表（`settings.css`、`agent.css`、`modals.css`、`connections.css`、`appearance.css`），提升长期维护性与可读性；
  - 修复外露 MCP 子界面在激活状态下因出现滚动条导致弹窗宽度微小抖动/闪烁的问题。
- **外部连接体系清晰重构与跨平台 IPC 协议抽象**：
  - 严格划分 Nami Mail 内置 MCP 客户端工具、本地外露 MCP 服务（面向 Claude Desktop / Cursor 等外部宿主）、以及外部 namimail CLI 命令行的定位与安全控制；
  - 完善外露 MCP 服务一键启动/重启/停止与配置范例快速复制，清晰展示读写授权等级（只读、发送需确认、完全访问）；
  - 提供已配对外部 CLI 令牌的管理与撤销能力；
  - 抽象统一的跨平台本地 IPC 通信层（`SupportedBrokerTransport`），同时支持 Windows 命名管道与 POSIX Unix Domain Sockets，解除单平台绑定，并执行严格的文件属主 UID 与 0600 文件权限校验。
- **模型上下文预算估计、工具结果剪枝与自动历史压缩**：
  - 支持在模型供应商配置中填写「上下文窗口大小（Tokens）」与「最大输出大小（Tokens）」；
  - Agent 在每次请求大模型与执行工具循环时，自动估算当前全量 prompt、历史消息与系统指令的 token 占用；
  - 当上下文达到警戒线（如 75% 预算容量）时，自动对超长工具执行输出（如大量邮件搜索结果、巨幅文本正文）执行智能结构化剪枝，防止单次工具调用撑爆模型上下文；
  - 自动对早期多轮历史消息执行上下文压缩与关键点摘要折叠，确保多轮复杂 Agent 对话不会因为超过上下文窗口而失败中断。
- **系统端到端性能指标可观测性完善**：
  - 服务端沙盒模拟执行全流程接入 `performance.now()` 高精度分段测量，输出初筛耗时、Token 压缩耗时、范围规则耗时、模型调用耗时与总执行耗时；
  - 前端结果卡片顶栏展示轻量微型耗时胶囊 Badge（`sandbox-latency-pill`），鼠标悬停展示完整耗时分段拆解；
  - 性能遥测系统接入 `recordAgentTiming` 与 `slow-agent` 指标项。

## 安全与范围

- 本版本未扩大任何外部网络访问面：本地优先原则始终如一，未开启外部公网端口；
- 本地外露 MCP 与 CLI 均仅监听本机安全命名管道或 Unix 套接字，并受到严格的配对授权与权限级别校验；
- 自动回复沙盒完全运行在只读或沙盒内存上下文中，杜绝任何外部发信副作用；
- 更新信任根保持不变：GitHub 更新资产继续使用 Ed25519 清单签名校验。

## 已知问题与限制

- **Outlook / Hotmail 账户在默认安装下暂无法直接登录（跟踪 Issue #120）**：
  - 微软已全面关闭 Outlook.com IMAP/SMTP 基础密码认证，仅支持 OAuth2；
  - 当前官方构建版本尚未内置 Azure 公开客户端 ID（OAuth Client ID），因此默认点击微软登录将提示暂不可用；
  - 如需使用，可在 `%APPDATA%\Nami Mail\nami-mail.env` 中配置 `NAMI_MAIL_MICROSOFT_OAUTH_CLIENT_ID` 环境变量以启用；该问题将在维护者完成 Azure 应用注册并在后续版本内置 Client ID 后彻底解决。
- **平台支持**：当前仅提供 Windows x64 桌面版。
- **搜索与检索**：本地检索不摄取附件正文；中文按单字切分，问法与邮件写法差异过大时依赖查询扩展，命中可能包含噪声。
- **第三方服务**：云端模型与翻译服务的可用性、配额和输出准确性取决于所选第三方服务提供商；机器翻译仅用于辅助阅读。
