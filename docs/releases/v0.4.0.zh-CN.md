# Nami Mail 0.4.0

[简体中文](v0.4.0.zh-CN.md) | [English](v0.4.0.en.md)

Nami Mail 0.4.0 是一次以稳定性为主的更新：修复 Agent 撤回后立即重发的一连串竞态与新邮件提示音"通知弹出但无声"的问题，补全会话线程与引用折叠，并上线官网与文档站。

## 下载

请只使用匹配 GitHub Release 页面列出的 Windows `.exe` 安装程序。版本化 ZIP、JSON 更新清单、`latest.yml` 和 `.blockmap` 用于发行与应用内更新，不是手动安装包。

## 更新与签名状态

- 发布前验收：CI 全量验证通过（typecheck / lint / 单元与集成测试 / e2e / desktop smoke / 依赖审计）；release job 在签名打包后运行 package smoke 并校验草稿资产完整性，通过后转正发布。
- 从 `0.3.0` 到 `0.4.0` 的公共网络自动更新验收仍待完成。本次发布不会在隔离验证完成前宣称在线升级链路已经验收通过。
- `0.4.0` Windows 安装程序未进行 Authenticode 签名。Windows SmartScreen 可能显示未知发布者警告。请勿绕过 Windows 安全警告，只应从本 Release 页面获取安装程序。
- 就地升级会保留现有本地数据；不会仅因本次更新而要求重新登录或重新授权账户。

## 本次更新

- **Agent 撤回/重发竞态修复**：会话回合持久化后服务端立即释放会话槽，收尾的首回合标题生成不再占用（慢供应商下它最长可挂约两分钟）；前端撤回遇"消息不存在"时采纳服务器快照对账并保留输入框待重发文本。撤回后立即重发不再被误拒、不再产生幽灵行或重复消息，也无需重新进入会话恢复。
- **新邮件提示音防静默**：主进程先播放、后弹横幅；播放失败自动回退为带系统音的通知并把原因写入运行日志；启动预热播放管线，消除首次通知约 1.5 秒的冷启动延迟；设置页"测试通知／测试提示音"与真实新邮件走同一条管线。
- **会话线程补全**：Gmail 式跨目录归组；缺失成员通过 `GET /api/messages/:id/thread` 补全（账户内 RFC 头双向传递闭包，排除草稿，逐行解密让出事件循环）；发送后自动补取。
- **引用自动折叠**：HTML 顶层引用折叠为原生 `<details>`，纯文本折叠尾部 `> ` 块；折叠只发生在渲染层，翻译与回复引用管线保持完整原文。
- **邮件方向展示修正**：自己发送的邮件按收件人渲染（阅读区头像/主名、列表 To 行与收件人头像、快捷回复预填原收件人），不再按文件夹名猜测方向。
- **列表切换闪烁修复**：列表标识只跟随已落地的快照身份，请求中旧行仅整体变暗。
- **Agent 搜索工具加固**：不再依赖搜索结果页 class 名（其变更曾导致永远返回 0 条结果），改为两步解析；检索活动展示真实查询词与结果概要（旧记录向后兼容）。
- **设置页精简**：删除 21 条冗余副标题、精简 11 条（中英同步）；下拉框字号与展开菜单一致；新增设置页本地化交互测试。
- **更新提示徽章化**：左下角圆形徽章悬停展开为"发现新版本 x.y.z"胶囊，关闭时分层动画退出；主文案由"本地加密"改为"数据留在本机"。
- **文件夹图标语义调整**：垃圾邮件改为盾牌加感叹号、所有邮件改为层叠样式，修复垂直对齐。
- **官网与文档站**：落地页 + 文档页自动部署到 GitHub Pages，中英双语切换。
- **依赖升级**：imapflow 1.7.8 → 2.0.2（TypeScript 化；上游修复 IDLE 自行结束后不重入）、react 19.3.0（react-dom 同步）、lucide-react 1.45.0、@tanstack/react-virtual 3.14.12。

## 安全与范围

- 本版本未扩大任何外部访问面：没有新增对外网络端点，邮件内容仍默认不出本机；会话线程补全与检索仅在本地数据库内完成。
- 更新信任链不变：GitHub ZIP 更新资产继续使用 Ed25519 清单签名校验，安装包内嵌公钥。
- 本地优先边界不变：账户凭据仅保存在本机，云端模型仅在用户明确选择并同意时使用。

## 已知限制

- 仅提供 Windows x64 桌面版。
- 本地检索不摄取附件正文；中文按单字切分，问法与邮件写法差异过大时（例如「报销」与「费用申请」）依赖查询扩展，命中可能包含噪声。
- 云端模型与翻译服务的可用性、配额和输出准确性取决于所选服务；机器翻译仅用于辅助阅读。
