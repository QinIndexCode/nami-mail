# Nami Mail 0.5.1

[简体中文](v0.5.1.zh-CN.md) | [English](v0.5.1.en.md)

Nami Mail 0.5.1 is a critical patch release resolving a core Windows updater issue where clicking "Restart and update" caused the application to exit silently without completing the upgrade or relaunching.

## Download & Critical Upgrade Guidance

- **Manual Upgrade Guidance (0.4.3 & 0.5.0 Users Only)**:
  Because the updater helper bundled within the running `0.4.3` and `0.5.0` installations contains the process detachment flaw, **in-app automatic updates cannot succeed from within 0.4.3 or 0.5.0. Users currently running 0.4.3 or 0.5.0 must download `Nami-Mail-Setup-0.5.1.exe` from this Release page and run it manually once**.
  - This manual in-place installation **completely preserves** existing local email data, accounts, settings, and encryption keys; no re-login or re-configuration is needed.
- **In-App Automatic Updates Restored for Future Releases**:
  Once updated to `0.5.1`, the updater core is fully patched; all future updates (such as 0.5.2, 0.6.0, and beyond) will support seamless, in-place silent background installation and automatic relaunch directly inside the app.
- Download only the Windows `.exe` installer listed on this release page. The versioned ZIP, JSON update manifest, `latest.yml`, and `.blockmap` are distribution and in-app update resources, not manual installers.

## Update & Signing Status

- Pre-release verification: Full CI test suite passed (typecheck, lint, unit & integration tests, e2e, desktop smoke, and desktop security); 268/268 desktop security and updater tests passing.
- `0.5.1` Windows installer uses Ed25519 manifest signature as update trust root; no Authenticode signature. Windows SmartScreen may display an unknown publisher warning. Do not bypass Windows security warnings; obtain installers only from this Release page.
- In-place upgrades preserve existing local data; re-login or re-authentication is not required.

## Key Changes in This Patch

- **Fixed Windows Background Updater Detachment & Silent Exit (Node.js Issue #51018)**:
  - Re-architected the helper launcher to avoid Node.js `spawn` with `detached: true`, which passes Win32 `DETACHED_PROCESS` and causes CUI console applications like PowerShell to fail ConHost initialization and exit silently with code 0 before running any script logic;
  - Replaced with Windows system shell `cmd.exe /d /s /c start "" powershell.exe -WindowStyle Hidden ...`, ensuring the update helper runs in an independent, fully initialized console session detached from the exiting Electron parent.
- **Added Missing NSIS In-Place Upgrade Arguments**:
  - Installer execution parameters now explicitly include `@('/S', '--updated')`, strictly aligning with `installer.nsh` to prevent unexpected running-process dialog prompts and protect custom installation paths (e.g. non-default drives) from being reset.
- **Fixed Working Directory Drift on Application Relaunch**:
  - Relaunching Nami Mail after update completion now explicitly specifies `-WorkingDirectory (Split-Path -Parent $CurrentExecutablePath)`, preventing the new application process from inheriting `C:\Windows\System32` as its current working directory.
- **Added Update Failure Cache Purge & Loop Circuit-Breaker**:
  - When startup detection finds that a recorded installation did not change the running version, the updater now purges the cached archive, permanently eliminating the infinite loop of recurring "Restart and update" prompt dialogs.

## Security & Scope

- Local-first principles remain intact: calendar, multimodal processing, and chat data are stored strictly on the local machine;
- Cloud models require explicit per-account mail authorization;
- Trust root remains intact: GitHub release assets continue to be validated against Ed25519 manifest signatures.

## Known Issues & Limitations

- **Outlook / Hotmail Accounts (Issue #120)**: Microsoft OAuth2 requirement; requires `NAMI_MAIL_MICROSOFT_OAUTH_CLIENT_ID` in `%APPDATA%\Nami Mail\nami-mail.env` until officially bundled.
- Windows x64 desktop only.
- Local search does not index attachment bodies; Chinese text segmented per character.
- Cloud models and translation availability depend on third-party providers.
