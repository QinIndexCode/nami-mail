# Nami Mail 0.3.0

[简体中文](v0.3.0.zh-CN.md) | [English](v0.3.0.en.md)

Nami Mail 0.3.0 引入首个正式的 External Mail v1 本机接口。该接口仅适用于 Windows 桌面版，面向已配对的本地脚本和 MCP 客户端，保持本地优先、默认拒绝和只读边界。

## 下载

请只使用匹配 GitHub Release 页面列出的 Windows `.exe` 安装程序。版本化 ZIP、JSON 更新清单、`latest.yml` 和 `.blockmap` 用于发行与应用内更新，不是手动安装包。

## 更新与签名状态

- 发布前验收：`0.3.0-m3acc` 构建已通过全部本地 smoke（desktop / package / installer）。desktop smoke 覆盖桌面桥、隔离数据目录与内容安全策略；package smoke 覆盖打包产物与安装程序；installer smoke 覆盖静默安装、CLI 路径注册、同/降版本升级策略与 MCP 冒烟，安装后 `tools/list` 返回 15 个 External Mail v1 工具。
- 从 `0.2.3` 到 `0.3.0` 的公共网络自动更新验收仍待完成。本次发布不会在隔离验证完成前宣称在线升级链路已经验收通过。
- `0.3.0` Windows 安装程序未进行 Authenticode 签名。Windows SmartScreen 可能显示未知发布者警告。请勿绕过 Windows 安全警告，只应从本 Release 页面获取安装程序。
- 就地升级会保留现有本地数据；不会仅因本次更新而要求重新登录或重新授权账户。

## 本次更新

- 新增安装包提供的 `namimail` PATH shim，并支持直接使用 `"Nami Mail.exe" --cli <args>` 调用。
- 新增 `namimail service start`、`status` 和 `doctor`，用于显式启动或检查本机 AgentHost；普通读取命令和 MCP stdio 不会隐式启动宿主。
- 新增桌面可见确认的 `namimail pair --profile <name>` 与 `namimail revoke --profile <name>` 流程。首次配对固定当前账户 ID 快照，新增账户不会自动进入旧 profile。
- 新增 `namimail mcp start --profile <name>` 本机 MCP stdio 接入。它使用 MCP `2025-03-26` 协议，并在 `tools/list` 中发布 15 个 External Mail v1 工具（8 个只读 + 7 个受限写入）。MCP 客户端配置需使用 `cmd /c` 宿主，详见 [MCP 配置](https://github.com/QinIndexCode/nami-mail/blob/main/docs/mcp/configuration.zh-CN.md)。
- External Mail v1 提供账户、文件夹、邮件列表、邮件详情、线程和附件元数据的读取，以及受限写入：草稿创建/更新/删除、邮件移动（归档/废纸篓）、已读/星标设置、发送与回复。成功数据由版本化严格 schema 验证，邮件正文为受限纯文本，附件不会导出文件。
- 为脚本和 MCP 提供稳定成功/失败包络、错误码、账户范围和更新排空恢复语义。GUI 主实例在命名管道 Broker 异常退出后会主动重建，避免"已运行但不可用"的假成功。
- 保留实验性的本地 NLLB-200 翻译。它仍只在桌面阅读器中由用户主动准备和触发，不是 CLI/MCP 工具。
- 新增邮件模板库：可在设置中管理常用主题与正文模板，撰写或回复邮件时一键插入。
- 新增附件内联预览：PDF 与图片直接在只读预览中渲染；DOCX / PPTX / XLSX 与常见文本文件提取只读文本预览，不导出原始文件。

## 安全与范围

- CLI/MCP 仅通过已配对、仅当前 Windows 用户 SID 可访问的命名管道 Broker 访问正在运行的宿主。
- 不能复用 Fastify token、HTTP/TCP、SQLite、文件 URI、邮箱凭据或数据库路径作为集成通道。
- 每个 profile 有独立受保护身份、签名和单调计数器；撤销、身份不匹配和重放均会被拒绝。
- 外部 v1 的写入仅限受限草稿与发送操作：草稿创建/更新/删除、移动（归档/废纸篓）、已读/星标设置、发送与回复。不支持转发、账户配置变更、RAG、聊天或附件导出。

## 已知限制

- 仅提供 Windows x64 桌面版。
- MCP v1 不公开 Resources、流式邮件事件或隐藏工具；客户端应每个新会话重新调用 `tools/list`。
- 云端模型与翻译服务的可用性、配额和输出准确性取决于所选服务。机器翻译仅用于辅助阅读。
