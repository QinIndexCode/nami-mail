# Nami Mail 0.5.0

[简体中文](v0.5.0.zh-CN.md) | [English](v0.5.0.en.md)

Nami Mail 0.5.0 is a milestone release: introducing a full-stack local calendar (month view, event CRUD, ICS import/export, and meeting invite banners with direct join links), end-to-end multimodal model integration (image, audio, video, and PDF context attachments), an extensive UI design system and visual overhaul (restored radius tokens, concentric corner principle, hidden sidebar scrollbars, full-width markdown tables, and translucent frosted skeleton screens), real-time account sync state visibility, agent streaming resilience and context budget hardening, and desktop auto-update pipeline stability enhancements.

## Download

Download only the Windows `.exe` installer matching this GitHub Release page. The versioned ZIP, JSON update manifest, `latest.yml`, and `.blockmap` are used for distribution and in-app updates, not manual installation.

## Update and Signing Status

- Pre-release verification: full CI validation passed (typecheck, lint, unit & integration tests, e2e, desktop smoke, dependency audit); the release job executes package smoke and verifies draft asset integrity before publication.
- `0.5.0` Windows installer uses Ed25519 manifest signature as its update root of trust; it is not Authenticode signed. Windows SmartScreen may show an unknown publisher warning. Do not bypass Windows security warnings; obtain the installer only from this Release page.
- In-place upgrades preserve existing local data; updating does not require re-login or re-authenticating accounts.

## What's New

- **Full-Stack Local Calendar & Meeting Invites (Calendar)**:
  - Built-in local calendar domain: month view browsing, event creation, editing, deletion, and search;
  - Mail calendar invite banner: reading messages with `.ics` attachments automatically displays event title, time, and location, with automatic recognition of Tencent Meeting, Zoom, Feishu, DingTalk, Teams, and Google Meet links;
  - ICS import with UID in-place deduplication: import and export ICS files; append imports deduplicate by ICS UID and update in place (upsert), preventing double-booking;
  - Attachment parsing capacity guard: parsed results cached per message part; strict 10 MB attachment cap and 50,000-line limit to defend against decompression bombs;
  - 15-minute pre-event in-app toast reminders linking directly to the calendar;
  - Calendar data stored strictly in local SQLite database with zero third-party or remote CalDAV synchronization.
- **Multimodal Model Integration & End-to-End Attachments (Multimodal)**:
  - Independent modality toggles in Agent provider settings to explicitly enable image, audio, video, and PDF document support;
  - Dynamic file filtering: the Composer attachment picker automatically reflects the active model's modalities, filtering unsupported files and displaying dedicated category icon badges;
  - Protocol normalization: end-to-end adaptation across OpenAI Chat, OpenAI Responses, Anthropic Claude, and Google Gemini native multimodal specifications with base64 and media URL streaming;
  - Backward compatibility: legacy models strictly degrade to plain-text mode to prevent upstream API failures.
- **UI Design System & Visual Polish**:
  - Restored design system soft radius tokens (`--radius-sm: 8px`, `--radius-md: 12px`, `--radius-lg: 20px`), eliminating harsh borders across buttons, rows, and cards;
  - Concentric radius principle ($R_{inner} = R_{outer} - padding$), eliminating inner corner distortion on agent marks and conversation headers;
  - Hidden sidebar scrollbars (`scrollbar-width: none`) while preserving smooth gesture and wheel scrolling without layout jitter;
  - Eliminated legacy purple accents, standardized on a monochrome minimalist neutral palette with clean single-line dialog headings;
  - Portaled modal dialogs to the document body, resolving nested dialog z-index and stacking context clipping traps;
  - Isolated agent transcript scrubber scrolling to container coordinates, eliminating layout shift;
  - Prevented false thinking indicators when opening completed historical sessions;
  - Wrapped agent markdown tables in `.agent-table-wrap` for full-width layout without right-side voids;
  - Replaced solid user loading skeletons with translucent frosted bubbles and shimmering sweep animation (`0.25 ~ 0.65`) matching assistant skeletons.
- **In-Progress Account Syncing Visibility**:
  - Real-time in-memory `syncing` indicator on accounts with a live pulsing dot and status subtitle in the sidebar;
  - Hardened concurrent timing between folder navigation and silent polling to prevent cross-folder overwrites.
- **Agent Streaming Resilience & Tools Hardening**:
  - Malformed tool JSON self-healing fallback for OpenAI-compatible providers;
  - Threshold-triggered pruning for long tool results and automatic multi-turn history compression;
  - Tool preprocessors and session tree scroll containment for uninterrupted long streaming.
- **Architecture Decomposition & Engineering**:
  - Decomposed the 4,355-line `App.tsx` monolith into 8 domain hooks and presentation components;
  - Zeroed ESLint warnings and relaxed full-core parallel test timeouts to eliminate CI flakes.
- **Desktop Auto-Update Pipeline Stability**:
  - Dedicated update download write lifecycle management, detaching paired error listeners on backpressure drain;
  - Atomic rename before committing update preferences to prevent corrupted package retention.

## Security & Privacy Scope

- Local-first architecture preserved: calendar, multimodal attachment parsing, and conversation data remain strictly local;
- Cloud models require explicit user opt-in for mail-content access before retrieving scoped messages;
- Update trust root unchanged: GitHub update assets verified via Ed25519 manifest signature.

## Known Issues & Limitations

- **Outlook / Hotmail Accounts (Issue #120)**: Microsoft enforces OAuth2; until official builds bundle an Azure Client ID, direct Microsoft login remains disabled unless `NAMI_MAIL_MICROSOFT_OAUTH_CLIENT_ID` is set in `%APPDATA%\Nami Mail\nami-mail.env`.
- **Platform Support**: Windows x64 desktop only.
- **Search & Retrieval**: Local search does not index attachment bodies; Chinese text segmented per character.
- **Third-Party Services**: Availability and rate limits depend on chosen third-party AI and translation providers.
