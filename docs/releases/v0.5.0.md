## 简体中文

### 下载

请只下载本 Release 页面列出的 Windows `.exe` 安装程序。版本化 ZIP、JSON 更新清单、`latest.yml` 和 `.blockmap` 是发行与应用内更新使用的资源，不是手动安装包，不应自行解压或运行。

### 主要变化

- **全栈本地日历与邮件会议邀请体系（Calendar）**：月视图浏览、事件管理、ICS 导入导出与邮件邀请横幅直达会议；追加导入按 UID 原地去重；严格 10MB 附件上限与 5 万行解析防护；15 分钟日程提醒；数据完全保存在本机 SQLite 数据库中。
- **多模态大模型接入与端到端附件传输（Multimodal）**：模型配置支持独立开启图片、音频、视频与 PDF 文档处理；Composer 附件选择器自适应过滤格式并以专属图标 Badge 呈现类别；端到端适配 OpenAI/Anthropic/Gemini/Ollama 原生多模态协议；未配置多模态的模型严格降级为纯文本，保障数据向后兼容。
- **全套 UI 设计系统重构与视觉体验升级**：恢复全局设计系统软圆角 Token（8px/12px/20px）；贯彻同心圆角法则（$R_{inner} = R_{outer} - padding$）；隐藏侧边栏滚动条（保留触控与滚轮平滑滚动）；消除紫色高光，统一单色调极简中性视觉与单行标题；模态弹窗使用 Body Portal 传送门渲染；修复历史记录擦除滚动导致整体页面上移的缺陷；封禁已结束历史会话误触发思考态；Agent Markdown 表格全宽排版优化（包裹 `.agent-table-wrap`）；对话加载骨架屏用户方重构为半透明磨砂气泡配对流光扫掠动画。
- **账户同步进行时态感知**：账户状态新增运行时 `syncing` 标志，侧边栏即时显示"正在同步…"脉冲状态点与说明；硬化文件夹切换与静默轮询的并发时序保护。
- **Agent 流式鲁棒性与工具加固**：损坏工具 JSON 自愈降级重试；超阈值智能剪枝长工具结果并自动折叠多轮历史；增加工具前置处理器与会话树滚动保护。
- **架构解耦与工程治理**：拆分 4355 行超大单体 `App.tsx` 为 8 个领域 hooks 与子组件；清理 ESLint 告警；调优测试超时阈值消除 CI flaky。
- **桌面端自动更新管道稳定性**：独立写入生命周期管理；背压释放时解绑错误监听器；原子重命名落盘后再提交偏好。

### 更新与签名状态

- 本版本使用 **Ed25519 清单签名**作为更新信任根；**未进行 Authenticode 签名**，因此 Windows SmartScreen 可能显示"未知发布者"警告。请勿绕过 Windows 安全警告，只从本 Release 页面获取安装程序。
- 就地升级会保留现有本地数据；不会仅因本次更新而要求重新登录或重新授权账户。

### 已知问题与限制

- **Outlook / Hotmail 账户在默认安装下暂无法直接登录（跟踪 Issue #120）**：微软已关闭密码认证强制采用 OAuth2，由于官方构建尚未内置 Azure OAuth Client ID，当前微软登录暂不可用；可在 `%APPDATA%\Nami Mail\nami-mail.env` 配置 `NAMI_MAIL_MICROSOFT_OAUTH_CLIENT_ID` 环境变量临时使用。
- 仅提供 Windows x64 桌面版。
- 本地检索不摄取附件正文；中文按单字切分。
- 云端模型与翻译服务可用性取决于所选第三方服务提供商。

## English

### Download

Download only the Windows `.exe` installer listed on this release page. The versioned ZIP, JSON update manifest, `latest.yml`, and `.blockmap` are distribution and in-app update resources, not manual installers — do not extract or run them yourself.

### Highlights

- **Full-Stack Local Calendar & Meeting Invites**: Month view, event management, ICS import/export with UID in-place deduplication, mail invite banners with direct meeting join links, 15-minute reminders, and strict 10 MB / 50k-line safety limits; local SQLite storage only.
- **Multimodal Model Integration & End-to-End Attachments**: Independent toggles for images, audio, video, and PDF documents in agent provider settings; adaptive Composer attachment picker with file category badges; end-to-end normalization across OpenAI, Anthropic, Gemini, and Ollama; strict plain-text fallback for backward compatibility.
- **UI Design System & Visual Overhaul**: Restored radius tokens (8px/12px/20px); concentric corner radius principle ($R_{inner} = R_{outer} - padding$); hidden sidebar scrollbars; monochrome minimal neutral styling; body portaled dialogs; fixed transcript scrubber page jumping; prevented false thinking indicator replay; full-width markdown tables (`.agent-table-wrap`); translucent frosted user skeleton screens with unified shimmer sweep.
- **In-Progress Account Syncing Visibility**: Live pulsing dot and status subtitle for active account sync passes; hardened concurrent request timing during folder navigation.
- **Agent Streaming Resilience & Tools Hardening**: Malformed tool JSON self-healing fallback; automatic token budget estimation, tool pruning, and history compression; tool preprocessors and session tree scroll isolation.
- **Architecture Decomposition & Engineering**: Split 4,355-line `App.tsx` monolith into 8 domain hooks and presentation components; zeroed ESLint warnings; eliminated parallel test flakes.
- **Desktop Auto-Update Pipeline Stability**: Dedicated download write lifecycle management, unhooked error listeners on drain, and atomic rename before committing preferences.

### Update and Signing Status

- Uses **Ed25519 manifest signature** as update trust root; **no Authenticode signature**, so Windows SmartScreen may display an "unknown publisher" warning. Do not bypass Windows security warnings; obtain installers only from this Release page.
- In-place upgrades preserve existing local data; re-login or re-authentication is not required.

### Known Issues & Limitations

- **Outlook / Hotmail Accounts (Issue #120)**: Microsoft OAuth2 requirement; requires `NAMI_MAIL_MICROSOFT_OAUTH_CLIENT_ID` in `%APPDATA%\Nami Mail\nami-mail.env` until officially bundled.
- Windows x64 desktop only.
- Local search does not index attachment bodies; Chinese text segmented per character.
- Cloud models and translation availability depend on third-party providers.
