开始前，可能想问的几件事。A few things before you start.

支持哪些系统？Which platforms are supported?

目前提供 Windows x64 安装程序，下载与安装步骤见安装指南。The installer supports Windows x64. See the installation guide for download and setup steps.

必须配置 AI 才能用吗？Do I need to configure an AI model?

不需要。收发、阅读、草稿和邮件筛选可以独立使用。需要助理时，再配置本地或云端模型。No. Sending, reading, drafts, and filters work independently. Configure a local or cloud model when you want the assistant.

邮件会发送到 Nami Mail 的服务器吗？Does mail pass through a Nami Mail server?

客户端直接连接邮箱服务商，本地保存邮件数据。主动使用云模型、翻译或外部工具时，相关内容可能发送到对应服务，具体范围见隐私说明。The client connects directly to your provider and stores mail locally. Cloud models, translation, and external tools may receive task-related content when you use them; see the privacy guide for the scope.
