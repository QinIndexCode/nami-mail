常见问题

你可能想问

邮件数据真的只存在本机吗？

是。Nami Mail 通过 IMAP 协议直接连接你的邮箱服务器同步邮件，数据存储与语义索引均在本机磁盘，不会上传至邮箱服务器之外的任何地方。没有账号体系，也没有云同步。

Agent 会把邮件发给模型吗？

默认不会。Agent 的检索基于本地 RAG 索引；使用云端模型时，邮件内容是否随请求发送由你通过"云端邮件内容许可"显式控制，本地模型则完全不出本机。

支持哪些邮箱？

任意支持 IMAP 的邮箱均可接入，包括 Gmail、QQ 邮箱、163、Outlook 及自建邮箱服务器。支持应用专用密码与 OAuth 授权。

是否支持 macOS 与 Linux？

当前正式版本面向 Windows。macOS 与 Linux 已在路线图中，规划随后续正式版本推出。
